## 截图规范建议

为视觉一致 · 截图前过这几条:

1. **浏览器宽度** · 1440px(模拟 MacBook 13 寸 · 大部分代理用户屏幕)
2. **缩放** · 100% · 别 Retina 截 2x 然后缩
3. **数据** · **真实但脱敏** · 客户名换"示例公司 A" · 手机号换 138\*\*\*\*0001
4. **高亮重点** · Snipaste / CleanShot 等工具加红框标注关键 UI 元素
5. **格式** · PNG · 浅色模式优先(深色模式截图后续单独做一套)
6. **命名** · 跟节点 slug 一致 · 如 `registration-form.png` / `diagnosis-step1.png`
7. **保存** · 上传 OSS · 在 `docs-data.ts` 用 https URL 替换 `screenshot-placeholder`

## 替换示例

收到截图后, 把 `docs-data.ts` 里:

```markdown
![注册表单](screenshot-placeholder)
```

替换为:

```markdown
![注册表单](https://omnirank.top/oss/help/registration-form.png)
```

`HelpDocs.tsx` 自动识别非 `screenshot-placeholder` 的 src · 渲染为真实 `<img>`(带 `rounded-lg` 样式)。
