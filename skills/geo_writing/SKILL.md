# GEO 内容创作技能

## 技能概述
本技能指导你创作符合 GEO（Generative Engine Optimization）优化规则的高质量内容，使内容能够被 AI 搜索引擎优先引用和推荐。

---

## 创作流程

### 第一步：明确写作任务
收集以下信息：
- **目标平台**：知乎/百家号/公众号/小红书等
- **文章主题**：核心主题是什么
- **目标关键词**：需要覆盖哪些关键词
- **目标受众**：读者画像
- **品牌融入**：是否需要融入品牌信息

### 第二步：获取平台规范
```
get_platform_style(platform="目标平台名称")
```

根据返回的规范调整：
- 标题风格
- 内容长度
- 语言风格
- 结构要求
- 禁忌事项

### 第三步：获取 GEO 优化规则
```
get_geo_rules(topic="内容结构")
get_geo_rules(topic="权威性增强")
get_geo_rules(topic="语言优化")
```

核心优化规则：
1. **结构清晰**：使用 H1-H4 标题层级
2. **开头点题**：关键信息放在段落开头
3. **列表优化**：使用列表、表格提升可读性
4. **数据支撑**：引用权威数据和研究
5. **专家背书**：添加专家观点
6. **时效标注**：注明数据来源和时间

### 第四步：获取标题公式
```
get_title_formulas(search_intent="用户搜索意图")
```

常用搜索意图类型：
- **购买决策**：哪个好/推荐/测评
- **问题解决**：怎么办/如何/教程
- **信息获取**：是什么/原理/科普
- **场景触发**：xxxx时该怎么办

### 第五步：采集素材支撑
```
search_web_for_geo(industry="行业", keywords="关键词")
search_scholar_for_geo(industry="行业", keywords="关键词")
```

需要的素材类型：
- [ ] 权威数据/统计
- [ ] 行业报告引用
- [ ] 专家观点
- [ ] 案例/示例
- [ ] 最新趋势

### 第六步：内容创作
按以下模板撰写：

```markdown
# [优化后的标题]

> **要点速览**：3-5个核心要点列表

## 背景/问题

简述背景，引出主题...

## 核心内容（分2-3个小节）

### 小节1：[关键点]

详细内容，包含：
- 数据支撑："根据[来源]的数据显示..."
- 专家观点："行业专家[姓名]指出..."
- 列表要点

### 小节2：[关键点]

...

## 实操指南/解决方案

具体可执行的建议...

## 总结

简洁有力的总结，重申核心观点

---

*参考资料：*
1. [来源1]
2. [来源2]
```

## 平台差异化指南

### 知乎（P0平台）
- **风格**：专业、深度、有理有据
- **长度**：2000-3000字
- **特点**：强调「个人经验+专业分析」
- **禁忌**：避免过度营销感

### 百家号/头条（P1平台）
- **风格**：通俗易懂、实用干货
- **长度**：1500-2000字
- **特点**：开头要有吸引力
- **禁忌**：避免敏感话题

### 小红书（社媒）
- **风格**：真实、有温度、种草感
- **长度**：500-1000字
- **特点**：emoji+口语化+关键词标签
- **禁忌**：硬广、虚假宣传

### 微信公众号
- **风格**：故事化、情感共鸣
- **长度**：1500-2500字
- **特点**：排版精美、配图讲究
- **禁忌**：标题党

## AI 引擎优化要点

让内容更容易被 AI 引擎引用：

1. **直接回答**：开头直接给出问题的答案
2. **完整方案**：提供完整解决方案，而非碎片信息
3. **结构化呈现**：使用表格、列表、步骤
4. **权威来源**：引用可验证的来源
5. **时效性**：包含最新数据和趋势
6. **长尾覆盖**：自然融入用户可能搜索的问题

## 质量检查清单

在提交内容前，检查以下项目：

### 结构检查
- [ ] 标题是否吸引人且包含关键词
- [ ] 是否有要点速览/TL;DR
- [ ] 标题层级是否清晰（H1-H4）
- [ ] 是否使用列表和表格

### 内容检查
- [ ] 是否有权威数据支撑
- [ ] 是否注明数据来源和时间
- [ ] 是否有具体案例或示例
- [ ] 关键词是否自然融入

### 平台检查
- [ ] 是否符合目标平台风格
- [ ] 长度是否在推荐范围
- [ ] 是否避开平台禁忌

### GEO 检查
- [ ] 是否直接回答用户问题
- [ ] 信息是否完整不碎片
- [ ] 是否有可验证的引用
