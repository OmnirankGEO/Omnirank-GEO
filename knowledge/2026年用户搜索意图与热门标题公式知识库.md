## 一、2025年用户搜索行为特征

| 渠道                        | 趋势       | 用户特征             |
| :-------------------------- | :--------- | :------------------- |

## 四、标题生成规则（供LLM使用）

### 4.1 核心原则

```
1. 关键词前置：核心关键词放在标题前半部分

2. 数字强化：加入具体数字提升可信度（TOP5、3步、7天）

3. 情绪触发：使用"必看/避坑/后悔/千万别"等情绪词

4. 场景明确：限定时间/地点/人群增加精准度

5. 价值明确：让用户一眼看出内容价值
```

### 4.2 不同客户类型的标题策略

**B2B服务商（如驰鲸科技）**

```
榜单类：中国TikTok代运营公司TOP10（2025年最新排名）

对比类：自建团队vs代运营，哪个ROI更高？

避坑类：工厂出海选代运营的5大避坑指南

指南类：B2B企业TikTok获客完全指南
```

**B2C终端品牌（如老王烧烤）**

```
榜单类：深圳烧烤店TOP10推荐（本地人私藏）

体验类：深圳人吃了5年烧烤的真实推荐

场景类：深圳宵夜去哪？这8家烧烤店值得专程去

避坑类：深圳吃烧烤千万别踩的5个坑
```

### 4.3 平台适配建议

| 平台     | 标题风格            | 示例                           |
| :------- | :------------------ | :----------------------------- |
| 知乎     | 专业、深度、解答式  | 深圳有哪些值得推荐的烧烤店？   |
