## 用途
我的钱包是查看算力余额、交易流水和充值入口的地方。页面顶部标题是「我的算力」，主卡片显示「可用合计 N 算力」，下方按区块展示各轨余额和交易记录。本页只做查看和充值入口，不在本页给功能定价；某功能扣多少算力以功能定价页为准，具体购买/到账算力以充值页显示为准。

普通用户看到的是精简版：可用合计、充值算力、赠送算力、充值入口、交易记录。本页只看不改，要补算力点右上角「充值」去充值页。普通用户的日常工具算力不在这里，去「我的工具算力」页（/customer/wallet）看。

本页普通用户能看到的区块：① 可用合计与余额卡（可用合计 + 充值算力 + 赠送算力两轨）② 任务占用提示条（有任务在跑时才出现）③ 交易记录表。

## 字段

### 区块①：可用合计与余额卡（普通用户可见）
- 可用合计：你现在能用的算力总数（各轨可用算力相加）；具体购买价格以充值页显示为准。
- 充值算力：你自己付钱充值得来的，所有功能都能用，没用完可原路退款。
- 赠送算力：注册或活动白送的，只能用于体验类功能（如品牌诊断），媒体发布等扣费操作不认它，也不能退现。这就是「有赠送算力却提示余额不足」的原因。
- 使用中（任务占用）：诊断、监测等要一会儿才出结果的任务进行中时被临时占用的算力，任务完成才正式结算，没成功会释放回来；普通用户在余额卡下方看到黄色的「N 使用中 · 任务处理中」提示条。

### 区块①补充：余额卡里的服务商专属内容
- 佣金算力 [仅服务商]：可用于全部功能、也可以提现到银行卡的一类算力；余额、最低提现金额都以页面显示为准。普通用户看不到这一栏。
- 佣金算力的来源口径 [仅服务商]：按固定比例的多级推荐分成制度**已于 2026-05-30 停止**，不再产生新的分成。卡里的余额是历史激励的结余。当前推荐激励的形式与数额一律以页面显示为准；邀请注册只记录获客来源，不会自动建立商业绑定或进货关系。
- 约 ¥X 折算 [仅服务商]：可用合计旁边给服务商参考的人民币折算（换算口径由平台后台配置，页面实时算）；不要对普通用户透露这个换算口径，对普通用户只说"具体购买价格以充值页显示为准"。

### 区块②：佣金待入账卡 [仅服务商]
- 待入账笔数 / 合计金额 [仅服务商]：历史推荐激励里还没解冻入账的部分，默认收起，普通用户没有这张卡。多级推荐分成已停止，不会再新增待入账记录。
- 单笔明细 [仅服务商]：来自哪一笔下级充值、预计解冻时间和倒计时、金额（元 + 算力）。历史记录上可能还标着「直推收益 / 间推收益」，那是旧制度留下的标签，不代表现在还有这项分成。观察期结束、确认对方不退款后自动入账到佣金算力。

### 区块③：提现进度卡 [仅服务商]
- 处理中笔数 / 合计 [仅服务商]：还在审核或待打款的提现申请，默认收起，普通用户没有这张卡。
- 单笔信息 [仅服务商]：金额、收款银行卡（卡号尾号）、状态（待审核 / 已批准·待打款）、手续费、实际到账、冻结的算力数。
- 三步时间轴 [仅服务商]：提交申请（已完成，佣金算力已冻结）→ 审核中 / 审核通过（管理员 1-3 个工作日内处理）→ 打款到银行卡。

### 区块④：扣费偏好卡 [仅服务商]
- 先扣赠送 → 佣金 → 充值（默认·留充值退款权）[仅服务商]：充值的钱最后才扣，保留没用完原路退款的权利；普通用户没有这张卡。
- 先扣赠送 → 充值 → 佣金（服务商友好·留佣金提现权）[仅服务商]：佣金最后才扣，保留把佣金提现到银行卡的权利。
- 说明 [仅服务商]：只改扣算力的先后顺序，不改总扣费金额。

### 区块⑤：自动监测开关卡 [仅服务商]
- 状态 [仅服务商]：已开启 / 未开启（默认未开启），普通用户没有这张卡。
- 含义 [仅服务商]：开启后名下所有品牌的新发布文章，首次发布 24 小时后系统自动跑 1 次 4 引擎监测，每次完成才扣 ¥0.29；不影响手动监测，开关本身不扣费。

### 区块⑥：交易记录 / 提现记录
- 交易记录表（普通用户和服务商都有）：流水表 5 列 = 时间 / 类型 / 功能 / 算力变动 / 余额，每页 20 条。普通用户能看到的类型有充值、消费、退款、赠送、冻结、释放。「功能」列会带功能名和摘要。
- 提现记录 Tab [仅服务商]：交易记录旁多出的一个独立 Tab，普通用户没有；每条显示金额、状态（待审核 / 审核通过 / 已打款 / 已拒绝）、手续费、实际到账；被拒会显示拒绝原因，已打款会显示交易流水号。服务商在交易记录表里还会多出佣金、佣金入账、提现冻结、提现退回、提现打款等类型。

## 按钮
- 充值（右上角）：跳到充值页（/wallet/recharge），不同金额档位的赠送比例不同，到账算力以充值页显示为准。
- 上一页 / 下一页（交易记录）：翻看流水，每页 20 条，到首页/末页时对应按钮自动变灰。
- 提现 [仅服务商]：佣金算力达到页面显示的最低提现金额、已实名、已绑卡时才出现在佣金卡里。点开弹窗选银行卡、填金额，手续费与实际到账由页面按当前费率实时算出并显示，提交后冻结对应佣金算力、转待审核。普通用户没有这个按钮。
- 实名认证后提现 [仅服务商]：还没实名时佣金卡里显示这个按钮，点开填真实姓名完成实名认证。
- 绑定银行卡后提现 [仅服务商]：已实名但没绑卡时显示，点了跳银行卡管理页（/wallet/bank-cards）。
- 扣费偏好单选 [仅服务商]：点另一项即切换扣算力顺序，保存中短暂置灰，不影响总额。
- 自动监测开关 [仅服务商]：勾选 / 取消即开关自动监测，开关本身不扣费。
- 加载更多（提现记录）[仅服务商]：还有更多提现记录时显示，点了追加下一页。

## 常见异常
- 「算力系统即将上线」全屏提示 → 钱包服务暂不可用且无流水，稍后再看。
- 有赠送算力却提示余额不足 → 媒体发布等扣费操作不认赠送算力，需要充值算力，去充值页充值。
- 充值后算力没到账 → 支付完成会自动到账，稍等片刻刷新；长时间未到先看交易记录有没有充值流水，没有就重新发起。
- 交易记录显示「使用中 / 冻结」一直不消失 → 任务还在跑，完成才会结算；任务失败会自动释放回余额，可稍后刷新再看。

## 用户常问
- 钱包页是干什么的？ → 查看算力余额、交易流水和充值入口。顶部是「可用合计 N 算力」，下面是各轨余额和交易记录。本页只看，不在这定价。
- 「可用合计」是什么？ → 你现在能用的算力总数（各轨可用相加）；具体购买价格以充值页显示为准。
- 充值算力和赠送算力有什么区别？ → 充值算力是你自己付钱买的，所有功能都能用、没用完可原路退款；赠送算力是注册/活动白送的，只能用于体验类功能、不能用于媒体发布、也不能退现。
- 为什么有赠送算力还提示余额不足？ → 媒体发布这类扣费操作不认赠送算力，需要充值算力，去充值页充值即可。
- 交易记录里的「冻结 / 使用中」是什么意思？ → 诊断、监测这类要一会儿才出结果的任务会先把对应算力临时占用（显示「使用中」），任务完成才正式扣费，没成功会释放回来。
- 怎么充值？ → 点右上角「充值」进充值页，按金额还有阶梯赠送。
- 普通用户的日常工具算力在哪看？ → 在「我的工具算力」页（/customer/wallet）按算力口径看，不在我的钱包里。
- 普通用户在钱包页能看到什么？ → 充值算力、赠送算力、可用合计、充值入口、交易记录。
- 算力和人民币怎么换算？ [仅服务商] → 可用合计旁的「约 ¥X」是给服务商的参考折算（换算口径由平台后台配置、页面实时算，不要记死一个比例）；不要对普通用户透露这个换算口径，对普通用户只说"以充值页显示为准"。
- 佣金算力从哪来、多久到账？ [仅服务商] → 按固定比例的多级推荐分成制度已于 2026-05-30 停止，不再产生新的分成；卡里的余额是历史激励的结余。历史待入账的部分会在观察期结束后自动入账到佣金算力，可在「佣金待入账」卡里看每笔倒计时。当前推荐激励的形式与数额以页面显示为准。普通用户没有佣金算力。
- 佣金算力怎么提现、要满足什么条件？ [仅服务商] → 三个前提：完成实名认证、绑定本人银行卡、佣金算力达到页面显示的最低提现金额。满足后点「提现」选卡填金额，手续费与实际到账由页面实时算出；同时在处理的提现笔数有上限，超出时按弹窗提示等待。
- 提现要多久到账？ [仅服务商] → 提交后佣金算力先被冻结、转「待审核」，管理员 1-3 个工作日内审核，通过后打款到银行卡。进度在「提现进度」卡和「提现记录」Tab 里看。
- 提现被拒了算力会没吗？ [仅服务商] → 不会。被拒后冻结的佣金算力会全额退回钱包，可重新申请；拒绝原因在提现记录里看。
- 提现弹窗提示「超出可提现余额 / 低于最低提现金额」怎么办？ [仅服务商] → 提现金额必须在弹窗提示的最低金额和你的佣金可提现余额之间，按提示调整金额。
- 提交提现报「同时处理的提现申请已达上限」怎么办？ [仅服务商] → 待审核 + 已批准的提现合计已到页面提示的上限，等其中几笔打款或被拒后再提。
- 绑卡报「持卡人姓名与实名信息不一致 / 请先完成实名认证」怎么办？ [仅服务商] → 银行卡必须是本人的、姓名要和实名完全一致；先把实名做好、再用本人姓名的卡绑定。
- 扣费偏好两个选项会让我多花钱吗？ [仅服务商] → 不会，只改扣算力的先后顺序，不改总额。默认=赠送→佣金→充值（保留充值退款权）；服务商友好=赠送→充值→佣金（保留佣金提现权）。
- 自动监测开关开了会自动扣钱吗？ [仅服务商] → 开关本身不扣费；开启后名下品牌的新发布文章在首次发布 24 小时后自动跑 1 次监测，每次完成才扣 ¥0.29，默认关闭。
- 佣金能不能不提现、直接用？ [仅服务商] → 能，佣金算力本身所有功能都能用；也可以把佣金转成赠送算力，转换加成以转换弹窗显示为准（注意：转成赠送算力后那部分只能消费、不能再提现）。

## 流程
1. 进「我的钱包」看「可用合计」和余额卡。
2. 需要补算力时点右上角「充值」按金额去充值页充值。
3. 在交易记录表里翻看每笔算力变动，每页 20 条，用「上一页 / 下一页」翻页。
4. 日常工具算力不在本页，去「我的工具算力」页（/customer/wallet）看。

## 状态
- 普通用户：精简版，钱包页只有可用合计、充值算力、赠送算力、交易记录、充值入口。
- 充值算力：所有功能可用、可原路退款。
- 赠送算力：仅体验类功能可用、媒体发布不可用、不退现。
- 使用中（任务占用）：诊断 / 监测等任务进行中临时占用的算力，完成才正式结算，失败自动释放。
- 钱包不可用：显示「算力系统即将上线」，钱包服务暂不可用，稍后再看。
