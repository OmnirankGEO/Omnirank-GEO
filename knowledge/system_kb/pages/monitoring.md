## 用途
持续追踪品牌在 AI 搜索里的「出现率」—— 在 AI 里搜你的关键词时，品牌有没有被推荐到。签约后，报价单里的关键词会自动进入监测；你也能手动加词、手动点一次监测、或开「定时监测」每天自动跑。每次监测会让四个 AI 引擎（豆包、通义/千问、DeepSeek、Kimi）就每个关键词提问，记录品牌有没有被提及，积累出现率趋势，帮你判断哪个词掉了、需要补发文章。

页面顶部有「监测 / 数据洞察」两个 Tab：监测 Tab 是词条表 + 功能卡片；数据洞察 Tab 是趋势深度分析（要先选中品牌/客户才能点）。普通用户看到的标题是「我的排名看板」，只监测自己的品牌；监测流程、计费两种身份完全一样。

## 字段
- 关键词（必填）：要监测的搜索词，如「深圳GEO优化公司推荐」。在「添加关键词」弹窗里必填。
- 目标品牌（可选）：要判断是否被提及的品牌名。
- 来源（合同 / 手动）：签约报价单带进来的词标「合同」，自己额外加的词标「手动」。区别：合同词只能归档不能删；手动词可以直接删。只有合同词支持「自动监测」开关。
- 出现率：核心指标。在 AI 里搜这个词时，品牌被四个引擎提到/推荐的加权比例（看的是「有没有被提到」，不是传统排名第几）。表里默认显示「累计平均出现率」（按周期平滑），鼠标移上去能看到「今日实时」值；某天实时掉了但累计仍达标会标一个⚠️。
- 达标 / 目标：每个词有条达标线（出现率目标），按客户买的套餐档定 —— 入门版 50%、标准版 65%、旗舰版 75%。近 7 天出现率 ≥ 目标线就是「达标」（绿✓），没到就「未达标」（红✗）。
- 变化：今日实时出现率相对昨日的涨跌；累计已达标时的单日大波动会显示成「波动」而不是惊悚的负百分比。
- 倒计时 / 服务期至 [仅服务商]：这个客户这一单买了多少天监测服务（通常按月卖）。倒计时主显「服务剩余 X 天」，副显「已达标 N/M 天」；服务期至 = 起算日 + 服务天数。到期显「已到期」，自然日跑完显「已交付」。是服务商盯客户交付进度用的。
- 监测间隔：定时监测的节奏由系统固定，每天自动跑 1 轮，不可自定义间隔。
- 客户查看链接 [仅服务商]：生成给客户看实时看板的链接，发给客户后他不用登录就能看、约 30 天有效、只看得到自己这一个品牌、看不到别的客户。是服务商交付给客户的工具。
- 投放平台 / 文章标题 / 文章链接 / 发布日期 [仅服务商]：录入媒体投放记录时填，作为给客户的交付凭证。

## 按钮
顶部条：
- 刷新：重新拉取当前品牌的关键词列表，免费。没选品牌/客户时灰掉。
- 开始监测（N）：对勾选的关键词发起一次监测，按钮上显示要扣的总算力（130 × 勾选词数）。没勾词时显示「请先勾选词条」不可点；监测中再点变成「监测中（点击取消）」可取消。发起前会弹一个 5 秒可反悔的提示（显示将扣多少算力），不是强阻断弹窗。
- 查看报告：拉最近一次完成的监测结果（词条 / 引擎 / 是否检出 / 检测时间），免费。没有记录提示「暂无检测记录」。
- 数据洞察（Tab）：切到趋势深度分析，免费。没选品牌/客户时点会提示「先选择客户，再查看数据洞察」。

功能卡片：
- 添加关键词：弹窗里加要监测的词，免费。加完算完成新手教程的「首次监测」步骤。
- 趋势报表：看出现率近 7 天趋势曲线 + 平均/最高/最低，免费。
- 定时监测：设自动巡检开关 + 当前品牌是否参与自动监测，详见下方「定时监测」段。
- 生成报告：选周报/月报/季报/年报，按当前监测数据自动汇总生成，免费；生成后去「报告管理」页看和编辑。
- 报告管理：跳转到报告管理页，查看和编辑已生成的报告。
- 客户门户 [仅服务商]：生成给客户看实时数据的查看链接（客户不用登录、只看自己的品牌），详见下方字段「客户查看链接」。
- 媒体投放 [仅服务商]：看投放记录、录入投放记录（给客户的交付凭证）。
- 操作日志 [仅服务商]：看自己的操作记录。
- 数据回退 [仅服务商]：把某次错误的监测结果整批撤销，免费。
- 服务期设置 [仅服务商]：设这个客户买了多少天监测服务、从哪天起算，影响倒计时和服务期至。

词条表内按钮：
- 自动监测开关（每行，仅合同词）：开/关这个词的每天自动监测。开通前会确认「每天 03:00 跑 4 引擎、每词每天按当前目录价扣算力」，确认框里会写明当次单价。
- 一键开启 / 一键关闭自动监测：把所有合同词的自动监测批量开或关，确认弹窗里显示每天总算力。
- 选中未达标（N）：一键勾选所有未达标的词，方便接着「追加文章」。
- 追加文章（N）：给选中的未达标词补发优化文章（每词默认 2 篇，可调 1-10 篇），点确认跳到写作页。补发本身在写作页扣文章生成的算力，不在监测页扣。
- 归档（每行 / 归档所选）：归档后停止监测，之后可在归档区恢复或续费重新开始监测，免费。
- 删除（仅手动词那行有）：删掉自己额外加的词，免费。合同词没有删除按钮，只能归档。
- 导出 Excel：把词条列表导出 CSV 表格，本地生成，免费。
- 更多 N 列 / 收起 N 列：展开或收起表格里折叠的附加列（如来源、变化等，窄屏默认收起）。

## 常见异常
- 「还没有监测中的客户 / 先给客户做 AI 体检、签约报价」 → 这个账号下还没有签约监测的客户/品牌，先走 AI 体检 → 报价 → 签约。空状态有「去做 AI 体检」「生成报价单」两个按钮。
- 「当前客户还没有监测数据 / 这个客户还没有已确认/已付款的监测报价」 → 选中的品牌还没签约监测。要么去生成报价单签约，要么手动「添加关键词」。
- 「开始监测」点不了、提示「请先勾选词条」 → 先在词条表里打勾选词。
- 开始监测后提示算力不足 → 充值后重试（监测用通用算力，赠送和充值算力都能用）。
- 监测时提示某引擎全部失败 → 该引擎暂时异常/不可用，本次会全额退回算力，稍后重试。
- 点「数据洞察」提示「先选择客户」 → 先选一个品牌/客户再看洞察。
- 定时监测开了但没扣费 / 没跑 → 设置本身不立即跑也不扣费；要到每天 03:00 系统巡检时、且该品牌开了自动监测、且余额够，才会跑并扣费。余额不足会自动暂停，充值后自动恢复。
- 出现率显示⚠️ → 今天实时出现率低于目标，但累计平均仍达标，属正常单日波动，不用慌。
- 变化列显示「波动」 → 累计已达标的词出现单日大幅波动，系统判定为正常波动，不是真掉了。

## 用户常问
- 立即监测扣多少算力 → 按当前每词目录价 × 勾选的词数计算（勾选后弹窗会显示这次一共多少算力），每个词都跑四个 AI 引擎（豆包、通义/千问、DeepSeek、Kimi）全量检测。
- 定时监测扣多少、和手动监测一样吗 → 单价一样，都按当前目录价按词扣。定时监测是每天自动跑一轮，所以是「每词每天一次」；手动监测是你点一次扣一次。两者都跑四个引擎全量，具体单价以开通/提交前确认页显示的为准。
- 定时监测怎么开 → 点「定时监测」卡片，先打开自动巡检总开关，再打开「当前品牌自动监测」；也可以在词条表里逐个词开自动监测开关，或用「一键开启自动监测」。
- 定时监测多久跑一次、能改频率吗 → 系统固定每天 03:00 自动跑 1 轮（系统会打散到 03:00-05:00 避免拥堵），频率不可自定义。
- 监测失败算力会退吗 → 会。用「先冻结、成功后结算」：发起时冻结算力，成功才正式扣，失败（含某个引擎整片异常）全额退回。定时监测同理，完成才扣、失败不扣。
- 定时监测余额不够了会怎样 → 自动暂停，不会欠费；充值后自动恢复。已经成功跑过、已扣的算力不退。
- 关掉某个词的自动监测，已扣的退吗 → 不退。用的是「完成才扣」模型，关闭只影响明天起不再跑。
- 监测能用赠送算力吗 → 能。监测用通用算力，赠送算力和充值算力都能用。
- 出现率怎么看、和排名啥区别 → 出现率 = 在 AI 里搜这个词时品牌被推荐的比例（四引擎加权）；看的是「有没有被提到」，AI 搜索没有固定排名榜，被不被推荐才是核心。表里默认显示近 7 天累计平均，鼠标移上去看今日实时。
- 「达标」是什么意思 → 这个词近 7 天出现率 ≥ 达标线就算达标（绿✓）。达标线按套餐定：入门版 50%、标准版 65%、旗舰版 75%。
- 「铺量中」是什么 → 词刚进监测、还在前期铺文章阶段，还没开始算正式出现率，过几天有数据后会进入「监测中」。
- 生成报告免费吗 → 免费。选周/月/季/年报，系统按当前监测数据自动汇总，生成后去「报告管理」看和编辑。当前周期没数据会提示「无监测数据」。
- 合同词和手动词有什么区别 → 合同词是签约报价单带进来的，只能归档不能删，且支持每天自动监测；手动词是自己额外加的，可以直接删，但不走自动监测。
- 归档和删除有什么区别 → 归档是停止监测但保留数据，之后能在归档区恢复或续费重新开始监测；删除是彻底去掉（只对手动加的词可用）。
- 关键词怎么自动进来的 → 走完诊断 → 报价 → 签约后，签约的关键词会自动进入监测；没签约就提示「当前客户还没有监测数据」。也可手动「添加关键词」。
- 哪个词没达标怎么办 → 点「选中未达标」勾上落后的词，再点「追加文章」给它补发几篇优化文章，过几天出现率会慢慢追上来。这就是「发文 → 盯出现率 → 哪个词慢了就补发」的运营闭环。
- 套餐的目标出现率是多少 → 入门版 50%、标准版 65%、旗舰版 75%，监测结果对照这个目标判断是否达标。
- 服务期 / 倒计时是什么 [仅服务商] → 服务期 = 这个客户这一单买了多少天监测服务（通常按月卖，约 30 天）；倒计时是离服务期结束还剩几天，提醒你在期内把词推到达标、到期前跟客户续费。到期后停止监测，续费会重新起算。
- 客户查看链接是干什么的 [仅服务商] → 是生成给客户看实时排名看板的链接，发给客户后他不用登录、只看得到自己这一个品牌、看不到别的客户、页面不露你的工作台。约 30 天有效，是服务商交付给客户看效果的工具。
- 媒体投放记录怎么来的 [仅服务商] → 代发订单完成后会自动同步进来（约 10 分钟）；非代发渠道自己投放的，走「录入投放」手动登记作为给客户的交付凭证。

## 流程
1. 进入排名监测，选好要看的品牌（普通用户默认就是自己的品牌）。
2. 在词条表里勾选要监测的关键词。
3. 点「开始监测」，确认后系统冻结算力、四引擎逐词检测，实时显示进度。
4. 用「趋势报表」「查看报告」看结果；想自动追踪就点「定时监测」开自动巡检 + 当前品牌自动监测。
5. 发现哪个词没达标，点「选中未达标」→「追加文章」补发，过几天再看出现率有没有追上来。
6. 想出周期总结就点「生成报告」出周/月报，去「报告管理」看和编辑。

## 状态
- 计费：手动监测按当前每词目录价扣算力（130 × N，N=勾选词数）；定时监测按当前每词目录价逐天扣算力。单价相同，都跑四个 AI 引擎全量检测。
- 扣费用「先冻结、成功后结算」：发起时冻结，成功转正式扣，失败（含某引擎整片异常）全额退回。定时监测「完成才扣、失败不扣」，余额不足自动暂停、充值后自动恢复，已扣不退。
- 监测用通用算力（赠送算力和充值算力都能用）。
- 免费操作：添加/归档/删除关键词、趋势报表、生成报告、查看报告、导出 Excel、追加文章的勾选动作（补发文章本身在写作页扣文章生成算力）。
- 套餐三档目标出现率：入门版 50%、标准版 65%、旗舰版 75%。
- 定时监测系统固定每天 03:00 跑 1 轮（打散到 03:00-05:00），频率不可调；需要总开关 + 当前品牌开关都开才生效。
- 出现率表里默认显累计平均（按周期平滑），鼠标移上去看今日实时；近 7 天、首次检出后开始算、自动排除前期铺量天。
- 来源分合同词（只能归档、支持自动监测）和手动词（可删、不走自动监测）。
