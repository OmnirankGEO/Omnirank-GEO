## 用途
充值算力。可以选固定套餐或自定义金额，再用微信完成支付，支付成功后算力到账钱包。按页面显示的金额和到账算力为准，并按金额梯度赠送算力。

## 字段
- 固定套餐（可选）：starter、popular、pro、flagship、premium、trial 等固定档位，每档对应固定金额和算力。
- 体验包 trial（可选）：¥0 免费领取的体验档，到账 3888 算力，无需付款；每个账号只能领一次，已领取后这张体验包卡会置灰、标"体验包 (已领取)"，再点会提示"体验包已领取"。
- 自定义金额（可选）：自己填充值金额，系统按金额算出基础算力和赠送算力。金额需在页面允许范围内（范围以充值页提示为准）。
- 支付方式（可选）：当前可用微信支付；支付宝显示"即将开通"，暂不能下单。
- 支付渠道（可选）：系统按你的设备/环境自动选择，微信内打开走微信内支付，电脑端显示二维码扫码，手机非微信环境走网页支付，无需手动选。
- 微信打开更丝滑引导卡（可选）：在手机非微信浏览器打开本页时，页面顶部出现一张绿色引导卡，写"在微信内打开本页可使用微信直连付款 · 更快更稳"，并带一个"复制本页链接"按钮；点了把本页链接复制到剪贴板（提示"链接已复制 · 微信内粘贴打开"），到微信里粘贴打开即可走更顺的微信直连付款。当前浏览器仍能正常付款。

## 按钮
- 套餐卡片：选中某个固定充值档位。
- 自定义金额：切到自定义充值，按你填的金额算算力。
- 微信支付：选择微信作为支付方式。
- 支付宝：点了会提示"即将开通"，不会真正下单。
- 立即充值：创建充值订单，然后按你的环境拉起微信支付或显示付款二维码。自定义金额不合法或正在请求时置灰。

## 常见异常
- 提示"金额无效" → 自定义金额低于最小值或超过上限，按页面提示的范围重新填。
- 提示"即将开通" → 选了支付宝，暂不可用，改用微信支付。
- 体验包卡点不了、置灰显示"体验包 (已领取)"或提示"体验包已领取" → 体验包每个账号只能免费领一次，你已经领过了，选其它套餐充值即可。
- 支付成功后算力没到账、订单还显示处理中 → 稍等片刻或刷新钱包页，系统会主动向微信核对订单兜底到账。

## 用户常问
- 充值页是干什么的？ → 充值算力。可选固定套餐或自定义金额，用微信完成支付，支付成功后算力到账钱包。规则对普通用户和服务商一致。
- 充值后多久到账？ → 支付成功后系统确认即到账，一般很快；偶尔延迟可刷新钱包页，系统会主动向微信核对订单兜底到账。
- 充值多少算力怎么算？ → 按页面显示的金额和到账算力为准，另按金额梯度赠送算力，赠送比例以充值页显示为准，金额越高赠送比例越高。
- 为什么支付宝不能用？ → 支付宝暂未开通，点了会提示「即将开通」，目前请用微信支付。
- 自定义金额怎么算赠送？ → 到账算力以页面显示为准，赠送按金额梯度叠加，金额越高赠送比例越高。
- 微信二维码和微信内支付有什么区别？ → 同一笔支付的不同入口：电脑端扫码、微信里直接付，结果一样，系统按你的设备自动选，无需手动切。
- 提示「金额无效」怎么办？ → 自定义金额低于最小值或超过上限，按页面提示的范围重新填。
- 自定义金额能填多少？ → 范围以充值页提示为准，在这个区间内任意填，系统按金额梯度送赠送算力（比例以页面显示为准），超出区间会提示「金额无效」。
- 体验包为什么点不了？ → 体验包是 ¥0 免费、到账 3888 算力的福利，每个账号只能领一次；你已经领过了，这张卡会置灰并标「体验包 (已领取)」，再点提示「体验包已领取」，选其它套餐充值即可。
- 在微信外打开页面顶部那张绿色「复制本页链接」卡是干嘛的？ → 你在手机非微信浏览器打开本页时出现的引导，点「复制本页链接」把链接复制到微信里粘贴打开，可以走更顺的微信直连付款；不复制也能在当前浏览器正常付款。
- 打开充值页会扣费吗？ → 不会，只有支付成功、订单确认后才增加算力。

## 流程
1. 进入充值页。
2. 选一个固定套餐，或切到自定义金额并填金额。
3. 选择微信支付。
4. 点"立即充值"创建订单。
5. 微信内直接拉起支付，电脑端显示二维码扫码，手机非微信环境跳网页支付。
6. 系统轮询订单状态，支付成功后刷新余额并跳回钱包页。

## 状态
- 加载中：创建订单、支付处理时按钮显示"处理中"。
- 成功：订单支付成功后刷新算力余额，并跳回钱包页。
- 失败：下单失败、渠道未开通、支付取消或超时会给出提示。
- 打开充值页不扣费；只有支付成功、订单确认后才增加算力。
- 本页只负责充值到账，对所有用户一致；服务商的经营相关内容不在本页。
