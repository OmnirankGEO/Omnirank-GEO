## 用途
销售定价是你给客户卖算力包、定价格、做包装的地方。平台按出厂价（你的进货成本）把一批算力包发给你，你在这里给每个包改展示名、副标题、卖点话术，设客户售价，决定上架还是下架，系统实时帮你算毛利和健康度。页面顶部还有两个全局工具：一键加价（按倍数批量给所有包定价）和客户充值返利（用你自己的赠送库存给客户返算力）。

包按用途分三个标签页（Tab）：通用算力包、场景推荐包、按需加购。三个 Tab 的卡片操作完全一样，只是包的用途和定位不同——下面分 Tab 说明。

何时用：上手做白标生意先来这里给所有包定一遍价（可以用一键加价省事）；接新客户前检查包装文案和上下架状态；想做促销时开充值返利。查看和保存定价都不扣费。

## 字段
- 出厂算力（只读）：平台给该包的算力数量，固定不可改。
- 出厂价（只读）：平台给你的进货成本价（已含出厂折扣，比平台标价便宜），客户看不到。
- 你的客户售价（必填）：卖给客户的零售价，必须大于 0。这是客户实际付的钱。
- 你的毛利：系统自动算，= 客户售价 − 出厂价，旁边显示毛利率百分比和一个健康度徽章。
- 展示名（对客户）：客户看到的包名称，自定。
- 副标题：客户看到的一句补充说明，自定。
- 补充话术 / 卖点：追加在标准话术后面的营销文案，自定（不会覆盖平台标准话术，是接在后面）。
- 上架 / 下架开关：控制这个包是否展示给客户购买。
- 加价倍数（出厂价 ×）：全局加价系数，填一个正数，一键把所有上架包售价定为"出厂价 × 倍数"。
- 返利开关：是否给客户充值返利。
- 返利比例（%）：0 ~ 100%，返利算力从你的赠送库存出。
- 单笔上限（算力·选填）：每笔返利最多返多少算力，不填表示不限。

## 按钮
- 刷新（右上角）：重新拉取算力包列表和当前的加价系数、返利设置，不动账、不扣费。
- 一键应用到所有包：按你填的加价倍数，把所有包的客户售价批量设为"出厂价 × 倍数"，你之前改过的展示名/副标题/卖点都会保留。
- 保存返利设置：保存对客户的充值返利规则（开关 / 比例 / 单笔上限）。
- 编辑包装 / 售价（每张包卡片里）：打开编辑弹窗，改展示名/副标题/卖点/客户售价/上下架，点"保存"生效。

## 三个 Tab 分别是什么
- 通用算力包：最基础的算力充值包，客户买了就是普通算力，能用在系统里各种功能上。给所有客户都适用，是你的主力走量包。
- 场景推荐包：针对特定使用场景预先组合好的包（按具体场景定位、给出推荐用途）。适合推给有明确需求的客户，话术里通常带场景卖点。
- 按需加购：客户在基础包之外临时加买的小额补充包。适合客户算力快用完时顺手加购，单价灵活。

三个 Tab 的卡片字段、编辑方式、健康度提示、保存规则完全一致。下面的异常、常问、截图指引在三个 Tab 通用，区别只在你给不同定位的包配不同的文案和价格。

## 常见异常
- 客户售价填 0 或负数 → 保存被拒，提示"零售价必须大于 0"。这是唯一的硬红线。想停售请用上架/下架开关，不要把价格填 0。
- 客户售价定得很高（超过出厂价 3 倍）→ 仍然能保存。系统只会标一个"利润过高·请确认"的红色徽章提醒你定价偏高，不会拒绝保存。
- 客户售价低于出厂价（亏本）或刚好等于出厂价 → 仍然能保存，系统标"亏本·确认可保存""微亏·确认可保存"或"平本"徽章提示。亏不亏自己负责。
- 加价倍数填 0 或负数、或没填 → 提示"加价系数须为正数"，改成大于 0 的数。
- 一键应用后提示某个包"未能应用 / 跳过" → 只有出厂价为 0 的"面议包"会被跳过（按倍数算出来还是 0、过不了"售价必须大于 0"），其它正常包都会成功定价。这不是"超上限被拦"。
- 返利比例填了超过 100% → 提示"返利比例须在 0 ~ 100% 之间"，改回 0~100。
- 单笔返利上限填了负数 → 提示须为非负整数。
- 编辑保存 / 一键应用 / 保存返利时提示要先签协议 → 先去签《工厂模式协议》，签完才能改定价。

## 用户常问
- 销售定价页是干什么的？（任一 Tab） → 这是你给平台各算力包设置卖给客户价格、做包装、配返利的地方。出厂价（你的进货成本）固定不可改，你自定客户售价和展示名/副标题/卖点，系统实时显示毛利和健康度。
- 通用算力包、场景推荐包、按需加购有什么区别？ → 通用算力包是基础走量算力包；场景推荐包是按具体使用场景组合好、带场景卖点的包；按需加购是客户临时补充的小额加买包。三种包的定价、改文案、上下架方式完全一样，只是定位和推荐对象不同。
- 出厂价是什么，客户看得到吗？ → 出厂价是平台给你的进货成本价（已含出厂折扣，比平台标价便宜），页面上只读不可改；客户完全看不到出厂价，只看到你设的客户售价。
- 毛利怎么算？ → 毛利 = 客户售价 − 出厂价。售价定得越高毛利越大，徽章会从"利润正常"涨到"利润较高""利润偏高""利润过高"。
- 售价能定多高？有上限吗？ → 客户售价唯一硬红线是必须大于 0，没有上限。超过出厂价 3 倍只会标一个"利润过高·请确认"的提示徽章，仍然能保存；定多高你自己说了算。
- 卖得比进货价还低（亏本）能保存吗？ → 能。系统只标"亏本/微亏"提示徽章，不拦截。亏本生意自负盈亏。
- 全局加价倍数怎么用？ → 在"全局加价系数"框里填一个正数（如 1.5 表示在出厂价上加 50%），点"一键应用到所有包"，系统把所有包售价批量设为"出厂价 × 倍数"，你之前改过的文案都保留。倍数必须为正数，没有上限。
- 一键应用为什么有的包没改成功？ → 只有出厂价为 0 的"面议包"会被跳过（算出来还是 0、过不了售价大于 0 的红线）。其它正常包都会成功。不是因为价格定太高被拦。
- 客户充值返利的算力从哪里出？ → 从你自己的赠送库存（赠送池）出，相当于你自掏成本给客户做促销。如果某笔充值时你的赠送库存不够，这笔返利会自动跳过，但不影响客户正常到账，也不影响你的主算力。
- 返利怎么设？ → 打开返利开关，填返利比例（0~100%），可选填单笔上限（每笔最多返多少算力，不填=不限），点"保存返利设置"。关闭开关或比例填 0 就是不返。
- 把包下架了，老客户还能用吗？ → 能。下架只是不再展示给客户购买，已经买过的客户手里的算力照常用。

## 流程
1. 选 Tab：在通用算力包 / 场景推荐包 / 按需加购里找到要定价的包。
2. 单个改：点该包卡片的"编辑包装/售价"，改展示名/副标题/卖点和客户售价，设上下架，点"保存"。
3. 批量改：在顶部"全局加价系数"填倍数（如 1.5），点"一键应用到所有包"，所有包按出厂价×倍数定价，文案保留。
4. 做促销：打开"客户充值返利"开关，填返利比例和单笔上限，点"保存返利设置"。

## 状态
- 健康度徽章（仅提示、不拦截保存）：亏本·确认可保存 / 微亏·确认可保存 / 平本 / 利润正常 / 利润较高 / 利润偏高 / 利润过高·请确认。除"客户售价必须大于 0"这条硬红线外，任何价格都能保存。
- 出厂算力、出厂价始终只读不可改；客户售价优先用你自设的值，没设过则用平台建议价。
- 一键加价只改售价、保留你已设的文案；倍数必须为正数、无上限；出厂价为 0 的面议包会被跳过。
- 返利算力从你自己的赠送库存出：开关关或比例为 0 即不返；某笔充值时库存不足则该笔自动跳过、不影响客户主算力到账；同一笔订单不会重复返。
- 查看、保存定价、配置返利、一键加价都不扣费；返利只在客户实际充值结算那一刻才从你的赠送库存扣。
