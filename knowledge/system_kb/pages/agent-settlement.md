## 用途
服务商查看各状态收益余额并发起提现申请。

## 字段
- 冻结中(T+3)（可选）：客户付款后冻结 3 天待解冻的收益，只读。
- 可提现（可选）：已解冻、可发起提现的金额，只读。
- 申请中（可选）：已提交提现申请、等待审核打款的金额，只读。
- 已打款（可选）：历史已打款总额，只读。
- 待抵扣（可选）：客户退款追回的金额，红色单独展示，不和可提现混算，只读。
- 累计预扣税（可选）：已从可结算金额中预扣的税款汇总，只读。
- 金额（必填）：本次申请提现的金额，默认填全部可提，须大于 0 且不超过可提现余额。
- 开户银行（必填）：收款银行，如招商银行。
- 银行账号（必填）：收款银行卡号。
- 账户姓名（必填）：开户人姓名。
- 需要发票（可选）：勾选表示提供发票（与协议第 8 条税务相关）。

## 按钮
- 刷新：重新拉取各池余额和可提现明细，不动账。
- 申请提现：打开提现申请框，填金额和收款信息后提交；仅当可提现余额大于 0 时可点击。
- 提交（提现框内）：提交提现申请，进入财务审核，对应收益被锁定。

## 常见异常
- 可提现为 0，"申请提现"按钮置灰 → 等收益过 T+3 解冻后再申请。
- 填的金额超过可提现余额或填了 0 → 改成大于 0 且不超过可提现的金额。
- 开户行/账号/户名漏填 → 三项均必填，补全再提交。
- 提交失败 → 刷新后重试，仍失败联系平台。

## 用户常问
- 我的收益什么时候能提现？ → 客户付款后收益先冻结 3 天（T+3），过冻结期转入"可提现"才能发起提现，没有最低提现额，只要大于 0 且不超过可提现余额即可。
- "待抵扣"是什么意思？ → 是客户退款后追回的金额，红色单独展示，不和可提现混算；它不会从你已结算的收益里直接扣，只是单独标出待抵扣部分。
- 提现要填哪些银行信息？ → 金额、开户银行、银行账号、账户姓名四项必填，是否需要发票可选；三项银行信息漏填或金额超过可提现都提交不了。
- 申请提现后多久到账？ → 提交后进入"申请中"等财务审核，审核通过打款后转入"已打款"；到账时间以财务打款流程为准。
- 预扣税是怎么回事？ → 默认按毛利 6% 预扣（协议第 8 条），已从可结算金额里扣掉；提供发票可改为"已提供发票"、个人可按"个人豁免"调整。

## 流程
1. 等收益过 T+3（3 天）冻结期，转入"可提现"。
2. 点"申请提现"，填金额、开户银行、银行账号、账户姓名（发票可选）。
3. 点"提交"，申请进入"申请中"，等财务审核。
4. 审核通过打款后金额进入"已打款"。

## 状态
- T+3：客户付款后冻结 3 天转为可提现。无最低提现额，只要大于 0 且不超过可提现即可。
- 提现按"先结算先提"（FIFO）锁定对应收益明细，同一笔收益的剩余金额可分次申请。
- 税默认 6%，已从可结算金额中预扣，提供发票或个人豁免可调整。
- 空态：无可提现明细时显示"暂无可提现明细"。
- 成功提示"提现申请已提交 · 等待财务审核"。
- 查看和申请提现不扣工具算力，仅锁定收益。
