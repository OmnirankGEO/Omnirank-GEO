## 用途
访客在公开诊断报告页或客户决策页留下联系方式（留资）后，分享该报告的服务商（顾问）在此页按意向度跟进这些线索。普通用户没有「分享报告→收线索」的业务，进来通常是空收件箱。本页全程不扣费、不碰订单和算力。

## 字段
- 公司名 / 品牌名：留资客户的公司或品牌。
- 手机号：客户留下的联系电话。
- 行业：客户所属行业。
- 关联诊断：诊断编号、等级、评分。
- 留资时间 / 状态更新时间：留资及最近状态变更的时间。
- 意向窗口文本：根据客户打开报告后多快留资判断意向强弱，越快意向越强。
- 状态：未跟进 / 已联系 / 已成交 / 已流失四档。
- 统计卡 ×5：全部 / 未跟进 / 已联系 / 已成交 / 已流失，各显数量；线索总数少于 10 条时显示「样本不足」。
- 客户归属[仅服务商]：线索归属哪个服务商（哪个服务商分享的报告收到的留资），属客户归属/线索分配概念。

## 按钮
- 刷新：重新拉取线索列表和统计。
- 筛选 Tab：按状态过滤线索。
- 点列表行：打开线索详情抽屉，看联系信息和客户行为时间线。
- 拨号联系：用浏览器拨打客户手机号。
- 复制微信号：复制手机号到剪贴板，去微信粘贴搜索。
- 复制客户信息：复制公司/手机/行业/诊断编号等多行文本，可粘到 CRM 或微信。
- 标记为已联系 / 改状态：在四档状态间切换，只改线索状态，不扣费。
- 跳客户工作台[仅服务商]：跳到该品牌的客户工作台跟进（服务商代客经营场景）。

## 常见异常
- 这页是空的 / 5 个 0 → 还没有客户留资。把诊断报告分享给客户，客户在报告或决策页填手机号后就会出现在这里（普通用户无分享则一直为空）。
- 卡片下显示「样本不足」 → 线索总数少于 10 条的提示，数据少不代表出错，多分享报告即可。
- 列表「加载失败 · 请刷新重试」 → 点刷新重试。

## 用户常问
- 为什么这页是空的 → 还没有客户留资。把诊断报告分享给客户，客户在公开报告页或客户决策页填手机号留资后，就会出现在这里（普通用户没有分享报告→收线索的业务，所以恒为空）。
- 样本不足是什么意思 → 线索总数少于 10 条时的提示，数据少不代表出错，多分享报告即可。
- 怎么联系客户 → 点开线索详情，用「拨号联系」打电话、「复制微信号」去微信搜、或「复制客户信息」粘到 CRM/微信。
- 线索状态怎么改 → 点开线索，新线索点「标记为已联系」，已跟进的在「改状态」里切「已成交」/「已流失」，只改状态不扣费。
- 强意向是怎么判断的 → 看意向窗口文本，客户打开报告后越快留资，意向越强。
- 标记状态会扣算力吗 → 不会，本页所有操作都不扣费，也不碰订单和算力。
- 客户线索归属哪个服务商 → [仅服务商] 线索按哪个服务商分享的报告收到留资来归属，属客户归属/线索分配概念。
- 怎么跳到客户工作台跟进 → [仅服务商] 点线索里的「跳客户工作台」进入该品牌的客户工作台，属服务商代客经营场景。

## 流程
1. 把诊断报告分享给客户，客户在公开报告页或决策页留下联系方式。
2. 留资线索出现在本页，按状态筛选查看。
3. 点开线索用拨号/复制微信/复制客户信息联系客户。
4. 跟进后更新状态（已联系/已成交/已流失）。

## 状态
- 普通用户：通常看到空收件箱，没有可跟进的线索。
- 加载中 / 错误态：分别显示转圈和红色错误提示。
