## 用途
发布中心把写好的文章发出去、让品牌内容被更多 AI 引擎收录。顶部有 6 个标签：代发（用平台权威媒体库帮你发，按媒体报价扣算力）、自助发布（用你自己的自媒体账号发，免费，需绑浏览器扩展）、发布记录（查所有订单状态、撤回/退款）、发布参谋（查看各平台在豆包/Kimi/DeepSeek/千问等 AI 引擎里被引用的调研数据，辅助选投放方向）、投放管理中心（按品牌看投放建议和投放台账结果回流）、手动确认（在平台外发稿后补录链接和截图，免费）。代发和自助发布都要先在左上角选写作项目、再选文章。

## 字段
- 选择项目（必填）：代发/自助发布顶上的写作项目下拉，选了左侧才出现该项目的文章列表。
- 代发媒体筛选（可选）：在代发里按媒体名、地区、资源类型、新闻源、门户、覆盖的 AI 引擎、价格区间、排序（默认按 GEO 权威分降序）筛权威媒体库。
- 自媒体筛选（可选）：代发里切到自媒体后，按平台（知乎/公众号/头条等）、行业、省份、粉丝区间、价格区间筛自媒体库。
- 文章分组标签（可选）：左侧文章按已发布 / 发布中 / 已拒稿 / 未分发四组归类，每篇只进一组。
- 报价（手动确认·必填）：手动确认里选一个报价单，选了才能选关联文章；只能选属于你自己的报价。
- 发布平台 + 发布 URL（手动确认·必填）：补录的平台名（小红书/公众号/知乎…或自填）和发布链接，链接必须是合法 http(s) 网址。
- 截图证据（手动确认·可选）：选图直传云存储（限 JPG/PNG/WebP、10MB 以内），也可手动粘贴任意图床链接。
- 投放项目（投放管理中心·必填）：选一个已确认的报价单项目，右侧才出现该项目的 AI 投放建议。
- 报价加价倍率（可选）：代发计费里媒体报价上浮的倍率，默认 1.5；属平台与媒体的结算口径，不对客户透露。[仅服务商]
- 媒体外采底价（可选）：每个媒体的外采底价（元），代发扣的算力由它换算；属平台-媒体结算口径，不对客户透露。[仅服务商]
- 代发支付算力类型（可选）：代发可用充值算力或佣金算力抵扣，赠送算力不可用；普通用户无佣金算力，只能用充值算力。[仅服务商]

## 按钮
- 加入购物车（代发）：把选中文章×选中媒体的组合存进购物车（只存本地浏览器，不下单、不扣费）；同一篇文章已在购物车里不会重复加。
- 批量加入（代发）：左侧勾了多篇文章时按钮变这个，一次把多篇配同一组媒体加进购物车。
- 一键发布（代发）：点了先弹「确认这次投放」风险弹窗，勾选「我已确认预算和风险」后才能点「继续投放」，确认后才真正下单、按服务端权威价扣算力、清空购物车。购物车为空时提示为空。
- AI 推荐（代发）：选中文章后自动分析（约 1-2 秒），给出均衡/覆盖/精准三套推荐媒体组合，点组合可一键勾选对应媒体，纯辅助、不下单、不扣费。
- 媒体卡片勾选（代发）：勾选权威媒体或自媒体，底部购物车栏实时显示篇数、媒体数、预计算力。
- 获取/生成绑定码（自助发布）：生成一个有时效的绑定码（带倒计时），把浏览器扩展和你的账号绑定；可点「刷新绑定码」重出一个。
- 去登录 / 已登录,刷新（自助发布）：账号显示「需重新登录」时，点「去登录」打开平台登录页，登录后回来点「已登录,刷新」刷新 Cookie。
- 创建草稿（自助发布）：用你这个在线账号把所有选中、且该账号还没发过的文章逐篇发成草稿，免费；账号离线或正在发布时点不动。
- 全部创建草稿 / 批量发布（自助发布）：对所有勾选的在线账号并行触发，跳过已成功的，免费。
- 重发（自助发布）：清掉某账号在选中文章上的发布状态，允许重新发一遍。
- 提交补录（手动确认）：把平台外发布的链接和截图写进发布记录，免费；同一个 URL 重复提交会命中已有记录、不重复建。
- 待确认（N）（顶部橙色按钮）：外部通道返回需人工决策的订单时出现，点开是待确认列表，每 5 秒刷新。
- 去处理 →（待确认列表内）：进文章编辑器，自动标红敏感词，改完点「保存并仍然发布」重新提交媒介审核。
- 取消发布并退款 / 一键取消全部并退款（待确认列表内）：取消单条或全部待确认订单，对应算力自动退回。
- 撤回（发布记录）：撤回一笔代发订单，确认后算力自动退还。
- 申请退款（发布记录）：对已完成订单填原因申请退款，提交后显示预计退还算力。
- 媒介代发 / 自助发布（发布记录顶部子标签）：切换看代发同步订单 还是 自助发布记录。
- 状态筛选（发布记录）：按全部 / 已完成 / 发布中 / 待接单 / 已拒稿 / 已撤回 / 已退款 过滤订单。
- 选投放项目（投放管理中心）：从已确认报价单里选一个，右侧出该品牌的 AI 优先投放建议。

## 常见异常
- 文章列表显示「请先选择项目」 → 先在左上角选一个写作项目。
- 一键发布提示购物车为空 → 先把文章和媒体加进购物车再点。
- 一键发布灰着点不动 → 还没勾「我已确认预算和风险」，勾上才亮。
- 一键发布提示算力不足 / 「赠送算力不可用」 → 代发不能用赠送算力，需要充值算力，去充值后重试。
- 提示「已有进行中的订单，请勿重复提交」 → 同一篇文章×同一媒体已下过单，别重复发，换个媒体或去发布记录看状态。
- 自助发布「创建草稿」点不动 → 账号离线，或这个账号正在发布中，等它发完或让账号上线。
- 自助发布账号显示「需重新登录」/红色 → 账号 Cookie 过期或被平台拒，点「去登录」重新登录该平台后点「已登录,刷新」。
- 手动确认提示「需要合法的 http(s) URL」 → 发布链接要填完整的 http:// 或 https:// 网址。
- 手动确认提示「该报价不属于当前账号·无权限」 → 选的报价不是你自己的，换成你名下的报价单。
- 投放管理中心右侧显示「从左侧选择报价单项目」 → 还没选项目，或名下没有已确认的报价单。
- 顶部出现橙色「待确认(N)」 → 有外部通道审核要你决策的订单，点开逐条处理；24 小时内不处理会自动取消并退款。

## 用户常问
- 代发和自助发布有什么区别 → 代发用平台的权威媒体库帮你发，按媒体报价扣算力、覆盖广、收录率高；自助发布是用你自己的自媒体账号（公众号/小红书/头条等）发，免费，但要先绑浏览器扩展并登录平台账号。想要权威媒体背书选代发，想省钱用自己号选自助。
- 代发怎么操作 → 左上角选项目→选一篇文章（可看 AI 推荐的均衡/覆盖/精准三套媒体组合）→勾媒体「加入购物车」→点「一键发布」→勾选确认预算和风险→「继续投放」，确认后才扣算力下单。加购物车和看 AI 推荐都不扣费。
- 代发怎么扣算力、用哪种算力 → 代发按所选媒体的报价扣算力，下单价格完全由服务端按权威媒体库重算（不接受前端上报价格）；用充值算力支付，赠送算力不能用。具体扣多少在下单前的购物车栏和确认弹窗里显示。
- 一键发布时算力不够会怎样 → 会拦下不下单并提示余额不足。代发不能用赠送算力，去充值后重试。
- 代发失败算力会退吗 → 会。代发订单里每个媒体单独计费，某个媒体发布失败后系统自动按条退回对应算力，不影响成功的那些。
- 自助发布要钱吗 → 完全免费。用你自己的账号发，先绑浏览器扩展、登录目标平台、生成绑定码绑定账号即可，平台不收算力。
- 自助发布怎么绑定 → 在自助发布标签点「生成绑定码」，在浏览器扩展里输入这个码（有时效，过期可刷新），绑好后账号会出现在列表里，再登录对应平台就能发。
- 发布记录有什么用 → 查你所有发布订单的状态。顶部分「媒介代发」和「自助发布」两个子标签，可按已完成/发布中/待接单/已拒稿/已撤回/已退款筛选；代发订单还能「撤回」（自动退算力）或「申请退款」。
- 发布参谋是干嘛的 → 它是查看各平台被 AI 引用情况的调研中心，按行业展示各内容平台在豆包、Kimi、DeepSeek、千问四个 AI 引擎里被引用的概率矩阵、引用详情和多引擎交叉引用来源，帮你判断该往哪些平台投放更容易被 AI 收录引用。普通用户/服务商在这里只看数据。
- 投放管理中心是干嘛的 → 按品牌做投放规划和结果回看。上方是媒体资源、GEO 收录、进行中项目、监测信源四个概览数字，左侧有「AI 高频引用信源」榜和「投放台账」（每次投放的结果状态、30 天 AI 引用变化、历史投放快照），右侧选一个报价单项目看 AI 给的优先投放建议。
- 手动确认需要算力吗 → 不需要，免费。手动确认只是把你在平台外（微信群、邮件外投、代投等）已经发好的稿件，补录链接和截图证据进系统，不扣任何算力。同一个链接重复提交不会重复记。
- 「待确认」是什么意思、怎么处理 → 外部发布通道审核时发现文章可能含敏感词或与历史文章重复，就把订单退回到「待确认」让你决定。点顶部橙色「待确认(N)」打开列表：点「去处理」进编辑器（敏感词自动标红），改完点「保存并仍然发布」重投；不想发就「取消发布并退款」，也能「一键取消全部并退款」。24 小时内不处理会自动取消并退款。
- 已发布/发布中分组怎么区分 → 优先级：已发布（有成功订单）> 发布中（订单进行中）> 已拒稿（只有失败订单）> 未分发（没下过单）；同一篇文章只归一组。
- 一篇已发布的文章还能再发吗 → 向同一媒体重复下单会被拒（提示已有进行中的订单，并自动退款）；可以换不同媒体发，或在发布记录/拒稿分组里用「重发」重投。
- 代发扣多少算力、怎么算 → 代发算力 = 媒体外采底价(元) × 加价倍率 × 130 后向上取整，加价倍率默认 1.5，由服务端按权威媒体库重算（不信前端价）。只扣充值或佣金算力，赠送算力不可用。底价和加价倍率属平台与媒体的结算口径，不要对客户透露价格明细，对外只说最终扣多少算力。[仅服务商]
- 代发能用佣金算力抵扣吗 → 可以。代发可用充值算力或佣金算力抵扣，赠送算力不可用；普通用户没有佣金算力，只能用充值算力。[仅服务商]

## 流程
1. 在左上角选写作项目，左侧出现文章列表
2. 选一篇文章（可参考 AI 推荐的三套媒体组合）
3. 代发：右侧选权威媒体或自媒体，「加入购物车」
4. 点「一键发布」，勾「我已确认预算和风险」后「继续投放」，扣费下单
5. 自助发布：切到自助发布标签，生成绑定码绑好扩展、登录账号后点「创建草稿/批量发布」
6. 平台外发稿的：切到「手动确认」，选报价、填平台和链接、传截图，「提交补录」
7. 在「发布记录」查订单状态，处理顶部「待确认」订单
8. 在「发布参谋」看引用数据、在「投放管理中心」看投放建议和结果回流

## 状态
- 代发：按媒体报价扣算力，用充值算力支付（赠送算力不可用）。一键发布点了先弹风险确认、勾选后才下单；下单时一次性扣费，某个媒体发布失败后自动按条退回算力。下单价格完全由服务端按权威媒体库重算，不接受前端上报价格。代发流程是「加入购物车 → 一键发布」，没有不经购物车的单篇直发。
- 自助发布：完全免费，用你自己的账号发，需先生成绑定码绑浏览器扩展并登录目标平台；账号离线或发布中时不能再触发。
- 手动确认：免费，仅补录平台外发布的链接和截图证据，同一个 URL 幂等不重复记，只能补录属于自己的报价。
- 发布参谋：在这里只查看各平台在 AI 引擎里被引用的概率矩阵、引用详情、来源分析，辅助选投放方向。
- 投放管理中心：看投放建议 + 投放台账结果回流（投放结果状态、30 天 AI 引用变化、历史投放快照），不在这里直接下单。
- 加入购物车、AI 推荐：免费。
- 文章分组：已发布（有成功订单）> 发布中（订单进行中）> 已拒稿 > 未分发。
- 发布记录订单状态：全部 / 已完成 / 发布中 / 待接单 / 已拒稿 / 已撤回 / 已退款；代发订单可撤回（自动退算力）或申请退款。
- 「待确认」：外部通道审核时返回需人工决策的订单（含敏感词或与历史重复），顶部出现橙色按钮，每 5 秒刷新；可改文重发或取消退款，24 小时不处理自动取消并退款。
