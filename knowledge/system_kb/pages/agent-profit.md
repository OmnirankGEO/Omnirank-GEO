## 用途
服务商的经营盈亏（P&L）仪表盘，一页看清本期"进货 → 卖货 → 结算"的财务盘子。

## 字段
- 客户付款（可选）：本期所有客户成交付款总额（GMV），只读。
- 进货成本（可选）：本期对应算力的出厂成本（服务商进货价），只读。
- 平台费（可选）：通道费 + 代收服务费，合计约 2.8%，只读。
- 代扣税（可选）：按毛利预扣的税，默认 6%，亏损时不扣，只读。
- 我的净收益（可选）：= 客户付款 − 进货成本 − 平台费 − 代扣税，平台按此打款，只读。
- 收益结算（可选）：冻结中(T+3) / 可提现 / 申请中 / 已打款 四项余额概览。
- 我的库存（可选）：可用库存、累计进货、累计开算力概览。
- 我的客户（可选）：客户数、客户预存未消耗算力概览。
- 我的消耗（可选）：你自己使用工具消耗的算力（非客户进货），近 5 笔 + 累计折算金额。

## 按钮
- 去报价方案：跳转到报价方案页，去给客户出报价。

## 常见异常
- 提示"经营数据暂时无法加载，或你还没有客户成交记录" → 还没有客户成交时正常显示空态；若确有成交则重新进入本页或稍后再看。
- "我的消耗"显示"暂无消耗记录" → 你本期还没用过工具，正常。

## 用户常问
- 经营总览这页是看什么的？ → 这是你的经营盈亏（P&L）仪表盘，一页看清本期"进货→卖货→结算"的财务盘子：客户付款、进货成本、平台费、代扣税、净收益，外加结算池、库存、客户和你自己工具消耗的概览。
- 净收益是怎么算出来的？ → 净收益 = 客户付款(GMV) − 进货成本 − 平台费 − 代扣税，这就是平台应打给你的钱。进货成本按你实际下单时的出厂价算(出厂折扣是平台后台可调的系统系数,以你下单当次的金额为准)。
- 平台费和税分别是多少？ → 平台费约 2.8%（通道费 0.9% + 代收服务费 1.9%）；税按毛利预扣 6%，毛利为负（亏损）时不扣税。
- "我的消耗"是什么，跟客户进货有关系吗？ → 没关系，两块成本分开核算。"我的消耗"是你自己用工具（诊断、AI 填写等）消耗的算力，页面会按平台当前换算口径折算成金额展示；进货成本是客户买算力包时你付给平台的出厂价，算在 P&L 里。
- 这里的钱怎么提现？ → 本页只看各状态余额（冻结中/可提现/申请中/已打款），实际提现要去"收益结算"页填银行信息提交申请。

## 流程
1. 看"经营损益"卡片：客户付款 → 进货成本 → 平台费 → 代扣税 → 我的净收益。
2. 看下方三张卡了解结算池、库存、客户概览。
3. 要提现去"收益结算"页；要出报价点"去报价方案"。

## 状态
- 净收益公式：客户付款(GMV) − 进货成本 − 平台费 − 代扣税 = 我的净收益。进货成本按你实际下单时的出厂价;平台费与预扣税比例都是平台后台可调的系统系数,**页面上的结算明细逐项列出当次实际数值**,本文不记死比例。毛利为负时不扣税。
- "我的消耗"由页面按平台当前换算口径折算成金额展示（换算系数后台可调，不记死数字）。
- 加载中显示旋转动画；本页全只读，不扣费。
