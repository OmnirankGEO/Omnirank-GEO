## 用途
登录后的首页工作台，展示问候语、算力余额和 GEO 业务概览，并提供新建诊断、写作、发布的快捷入口。全页只读，不扣任何算力。首页有两种形态：一种是「今日路线」引导式首页（顶部有问候语+余额、一张「今日路线」4 步引导卡、GEO 业务关键数字、快捷操作、最近发布/最近活动）；另一种是「工作台」概览式首页（上方四个数字卡 + 快捷入口 + 最近诊断记录）。两种都只读、都不扣算力，只是布局不同。

## 字段
- 问候语：按当前时段显示「早上好/下午好/晚上好，{昵称}」，昵称取自你的品牌名或资料名。
- 余额：显示「余额 N 算力」，N 为钱包可用算力合计，仅展示。
- 本月诊断：本月做过的诊断次数。
- 已写文章：累计生成的文章数。
- 今日路线（4 步引导卡）：在「今日路线」首页顶部，一排 4 个步骤卡，标出当前该做哪一步、做完的打勾。普通用户的核心动作是品牌体检和写文章；点每一步会跳到对应功能页。
- 品牌可见度：你品牌的最新 GEO 评分（如「85 分」），还没诊断时显示「—」。
- 管理品牌：名下品牌数。
- 品牌[仅服务商]：名下管理的客户品牌数（服务商客户池口径，普通用户语境无此含义）。
- 已发布[仅服务商]：代发成功的内容数（代发是服务商付费外采业务）。
- 今日跟进[仅服务商]：左栏客户优先级跟进队列，按意向度排出最紧急客户，跳客户工作台跟进。
- 经营话术卡[仅服务商]：「今日路线」首页里的一张经营玩法说明卡，讲清接客户、做体检、出方案、谈单的生意闭环，只有服务商身份才显示，普通用户看不到，可手动关闭。

## 按钮
- 新建诊断：跳 /diagnosis/new，给品牌做 AI 搜索体检。
- AI 创作中心：跳 /writing，根据方案生成文章。
- 发布中心：跳 /publish，发布内容和证据。
- 今日看板 →[仅服务商]：旧入口，已重定向回首页。

## 常见异常
- 四个数字全是 0 → 新账号或还没有数据；测试/已删除品牌会被过滤，属正常。
- 手机切到微信再回来数字变 0 → 已修复，回到页面会自动重新加载。
- 一个品牌都还没有、首页是引导页 → 这是空态：首页会显示「开启你的 AI 搜索占位之旅 / 开始第一次品牌体检」的引导卡，点按钮去做第一次品牌体检即可，属正常新手状态。
- 左侧空白没有今日跟进 → 没有待跟进客户时该区块整块不显示。
- 点「今日看板」跳回首页 → 该旧入口已废弃，自动回到首页，属正常。

## 用户常问
- 首页是干什么的？ → 登录后的首页工作台，展示问候语、算力余额和 GEO 业务概览，并提供新建诊断、写作、发布的快捷入口。全页只读。
- 首页会扣费吗？ → 不会，全页只读，扣费发生在诊断/写作/发布等具体动作页。
- 余额算力怎么来的、能点吗？ → 顶部「余额 N 算力」是钱包可用算力合计，纯展示、点不动；要充值或看明细去「我的钱包」。
- 本月诊断、已写文章是什么意思？ → 本月做过的诊断次数、累计生成的文章数。
- 怎么去做诊断 / 写文章 / 发布？ → 点首页快捷入口：「新建诊断」跳诊断页、「AI 创作中心」跳写作页、「发布中心」跳发布页。
- 首页顶部「今日路线」4 步是什么？ → 这是引导你按顺序把事情做完的步骤条，会高亮当前该做的那一步、做完的打勾，点每一步会跳到对应功能页；普通用户重点是做品牌体检、写文章，照着走即可。
- 我还没有品牌，首页是个引导页正常吗？ → 正常。还没有任何品牌时首页是空态引导，显示「开启你的 AI 搜索占位之旅 / 开始第一次品牌体检」，点按钮去做第一次品牌体检，有数据后首页就会显示你的评分和动态。
- 首页那张「经营话术 / 玩法」说明卡是什么？ [仅服务商] → 这是给服务商看的经营玩法说明卡，讲接客户、做体检、出方案、谈单的生意闭环，只有服务商身份才显示、可手动关闭；普通用户首页没有这张卡。
- 四个数字全是 0 正常吗？ → 正常。新账号或还没数据时为 0；测试/已删除品牌会被过滤。
- 手机切到微信再回来数字变 0 怎么办？ → 已修复，回到页面会自动重新加载。
- 点「今日看板」为什么跳回首页？ → 该旧入口已废弃，/dashboard/today 现已重定向回首页，属正常。
- 「品牌」和「已发布」这两个数字是什么？ [仅服务商] → 品牌=名下管理的客户品牌数（服务商客户池口径）；已发布=代发成功的内容数（代发是服务商付费外采业务）。普通用户语境无此含义。
- 左侧「今日跟进」是什么？ [仅服务商] → 客户优先级跟进队列，按意向度排出最紧急客户，点进可跳客户工作台跟进；没有待跟进客户时整块不显示。

## 流程
1. 登录后默认进入首页工作台。
2. 查看顶部问候语与余额，中部 GEO 业务四个数字。
3. 点「新建诊断 / AI 创作中心 / 发布中心」进入对应功能页开始干活。

## 状态
- 加载中：显示加载占位。
- 数据为空：四个数字显示 0，最近动态区块隐藏。
- 加载失败：数字静默回退为 0，可刷新页面重试。
