## 用途
学院风帮助主页，包含重走新手教程、新手必看视频、按工作流学的 4 步教程、概念科普，以及文档中心和 FAQ 入口。帮助中心全程免费，不扣任何算力。子页 /help/docs（帮助文档）和 /help/faq（疑难杂症问答）的内容也并入说明。

## 字段
- 重走新手教程卡：进入沙盒教程模式，跑通「诊断 → 报价 → 写文章发布 → 监测」全流程，数据不影响真账号、不会真扣费。
- 新手必看 Hero 视频：「几分钟看完怎么用」全流程演示。
- 按工作流学：4 步教程（做品牌诊断 / 出报价方案 / AI 写文章+发布 / 加监测追踪），每步带配套视频。
- 概念科普：什么是 GEO、评分怎么算、监测多久见效、算力怎么用等。
- 帮助文档（/help/docs）：左侧目录树 + 右侧文档正文，可搜文档标题，文档内截图可点开放大。
- FAQ（/help/faq）：常见问题手风琴列表，可按分类（计费/操作/数据/账号）筛选，可投票「有用/没用」（一人一票，可切换可撤销），可给工作人员提反馈。
- 反馈表单字段：反馈内容（必填，5~500 字）、关联 FAQ（选填）、紧急度（不急/影响业务/卡死了，默认不急）、联系方式（选填，最多 100 字）。无附件/截图上传功能。
- 权限受限文档（可选）：帮助中心里有部分文档仅特定权限可见，普通账号或服务商访问会提示权限不足，看不到内容。
- 服务商专属帮助主题[仅服务商]：佣金、提现、白标、利润、分销等服务商向说明，普通用户帮助中心不应出现这类内容（当前帮助文档对此尚未做身份过滤，普通用户实际仍可读到，属已知隔离待办，回答普通用户时不主动展开服务商专属内容）。

## 按钮
- 开始教程：进入沙盒教程模式，纯前端、不扣费。
- 视频缩略图：有视频则播放，没拍好的提示「视频制作中 · 联系运营」。
- 查文档：跳 /help/docs。
- 疑难杂症 FAQ：跳 /help/faq。
- 有用 / 没用：给 FAQ 投票，可切换可撤销。
- 给工作人员提反馈：打开反馈弹窗。
- 提交反馈：提交后工作人员跟进，答案补好会用系统消息通知你。

## 常见异常
- 点视频提示「视频制作中 · 联系运营」 → 该视频还没拍好。
- 反馈「提交反馈」按钮置灰点不了 → 反馈内容不足 5 个字，补够再提交。
- 反馈提交失败 → 系统会暂存到本地，下次打开 FAQ 页自动重发，不会丢。
- 访问某文档提示权限不足 → 该文档需要更高权限，普通账号看不了。
- FAQ 列表「加载失败」 → 点刷新重试。

## 用户常问
- 怎么重新看新手教程 → 点「重走新手教程」卡的「开始教程」，进沙盒走一遍，纯前端、不影响真账号、不扣费。
- 帮助中心会扣费吗 → 全程免费，教程、文档、FAQ、投票、反馈都不扣任何算力。
- 「开始教程」会污染真实数据吗 → 不会，进的是沙盒，纯前端演示，退出清进度后刷新即可。
- 怎么反馈问题 → 在 FAQ 页点「给工作人员提反馈」，填反馈内容（5~500 字）提交，工作人员补好答案会用系统消息通知你。
- 反馈能传截图吗 → 暂不支持附件/截图上传，反馈表单只有文字（内容、紧急度、联系方式）。
- 反馈提交失败怎么办 → 系统会暂存到本地，下次打开 FAQ 页自动重发，不会丢。
- 投票能取消吗 → 能，一人一票，可切换也可撤销。
- 投票为什么失败 → 多为网络问题，提示「投票失败」稍后再试即可。
- 文档里怎么找某个功能 → 在帮助文档（查文档）用左侧目录树或搜索文档标题定位。
- 为什么有的文档写「施工中」 → 不是账号问题，是该文档还没补完，等运营补充。
- 访问文档提示权限不足怎么办 → 该文档需要更高权限（权限受限文档），普通账号和服务商都看不了，属正常权限限制。
- 帮助中心里看到佣金/提现/白标/利润/分销这类内容 → [仅服务商] 这些是服务商专属帮助主题，普通用户帮助中心本不应出现（当前帮助文档尚未做身份过滤，属已知待办），回答普通用户时不主动展开。

## 流程
1. 进入帮助中心，先看新手必看视频或按 4 步工作流学。
2. 想动手练就点「重走新手教程」进沙盒走一遍。
3. 有具体问题去「查文档」或「疑难杂症 FAQ」。
4. 没找到答案就在 FAQ 页「给工作人员提反馈」，等系统消息回复。

## 状态
- 帮助主页：纯前端展示，无后端调用、不扣费。
- FAQ 列表：加载中 / 加载失败（可刷新）/ 空（没找到匹配问题）/ 正常四态。
- 反馈提交：成功提示「已记下你的反馈」；离线或失败暂存本地队列下次自动重发。
