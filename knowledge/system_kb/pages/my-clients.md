## 用途
管理你服务的客户档案的工作台。客户列表里能看到每个客户当前所处的阶段、GEO 资料评分、风险状态和资料完整度；可以新建、编辑、软删除、搜索、切换客户。点「打开客户」进入该客户详情页，详情页按 Tab 组织：基本信息、知识库、IP 人设、内容记录、诊断记录、语料库、互动记录；在详情页可用 AI 帮忙补全资料、润色单字段、做深度行业解析，也能直接发起诊断。普通用户通常没有下级客户，本页对你一般是空的。

## 字段
（客户列表页）
- 客户名称（必填）：新建客户时填，留空提示「请输入客户名称」；同名会合并到已有客户。
- 行业（可选）：从标准分类下拉选，或选「其他(自定义)」手填。
- 城市（可选）：影响后续扩词和地域定价。
- 搜索框（可选）：按客户名称或行业搜索，停止输入 300 毫秒后才查。
- 隐藏测试客户（开关，默认开）：隐藏名称含「测试/test/验收」等的演示品牌，关掉才看得到。
- 客户归属 [仅服务商]：客户挂在哪个服务商名下，列表里会显示归属信息，属服务商范畴，普通用户语境无此概念。
- 客户分成口径 [仅服务商]：客户产生的分成相关信息，属服务商范畴，普通用户不可知。

（客户详情页·基本信息 Tab 字段）
- 品牌/业务名、行业、城市、公司名称（C 端博主可不填）。
- 一句话业务描述、目标客户：这两个字段右侧有「润色」按钮。
- 产品/服务、客户痛点、竞争对手：标签输入，逗号或顿号分隔自动添加。
- 业务类型（B2C 终端消费者 / B2B 企业采购 / 政企）、地域范围（本地/区域 / 全国）：影响后续生成关键词。
- 市场洞察（权威信源 / 爆款形式 / 我的差异化等）：编辑卡，深度行业解析会自动补。
- AI 填过的字段会有琥珀色高亮 +「AI 填充·请检查」标记，提示你核对后再保存。

## 按钮
（客户列表页）
- 添加客户：打开弹窗，填客户名称（必填）+ 行业/城市（可选）创建。免费。建好后自动跳进该客户详情页。
- 打开客户 / 点整行：进入该客户详情页。免费。
- 切换：把当前操作的客户切换成这个，跳回首页。免费。
- 删除（垃圾桶图标）：确认后软删除，7 天内可在回收站恢复。免费。
- 批量升级（顶部黄色横幅里）[仅服务商]：当列表有资料完整度低于 80 分的客户时出现，批量 AI 补齐这些客户资料，属服务商批量经营动作；计费见用户常问。

（客户详情页·通用）
- 保存 / 保存客户资料：把基本信息、IP 人设、知识库 Tab 改动写库。免费。
- 删除客户（页面底部红色按钮）：软删除该客户，会一并归档其诊断记录和创作档案，需确认。免费。
- 更多客户动作（可折叠区）：展开后是诊断、报价、选词、监测、写作、发布、月报等工具入口，点对应卡片跳到相应功能页。

（基本信息 Tab）
- AI 智能填充：顶部面板，分「快速」和「顾问版」两个模式，AI 自动补全客户档案字段；快速模式输入公司名联网搜索或粘贴资料让 AI 提取，顾问版选一位 AI 顾问、读取该客户已上传的知识库做更深的结构化填充、能填更多字段。计费见用户常问。
- 润色（一句话业务描述 / 目标客户字段旁，以及知识库 Tab 营销写作资料各字段旁）：AI 润色单个字段；点后弹对比框，让你选「保留原文」或「用润色版」；选润色版后还要再点页面「保存」才真正写入。字段为空时按钮灰掉、不可点。计费见用户常问。
- 资料补齐向导横幅：完整度低于 80 分时自动出现，引导你补字段或一键 AI 填。

（知识库 Tab）
- 深度行业解析（开始解析 / 重新分析 / 重试）：AI 联网搜集你客户所在行业的目标人群、竞品格局、获客路径、爆款内容，生成行业知识库，系统处理约 3-8 分钟，失败/超时自动退费。计费见用户常问。
- AI整理资料（写作资料确认卡）：把你粘贴的客户官网/沟通记录等原始资料整理成写作素材。免费。
- 生成确认链 / 更新确认链 / 处理后重发：生成一条确认链接发给客户确认写作资料，AI 创作中心读取同一份资料。免费。资料不足时按钮灰掉。
- 复制 / 话术 / 外开（确认链旁）：复制链接、复制微信话术、新标签打开。免费。
- 上传客户资料 / 删除（客户资料文件）：上传官网介绍、产品手册、案例、报价单（pdf/doc/docx/txt/md/pptx），诊断、报价、写作都读这份。免费。

（IP 人设 Tab）
- AI 对话建档 / 手动编辑画像 / 上传语料学习 / 邀请面试：都是跳转入口，跳到对应功能页建立或编辑客户人设。本 Tab 只展示已有画像，不直接扣费。

（内容记录 Tab）
- 点某条内容记录：打开看为该客户生成过的文案/创作内容。免费。

（语料库 Tab）
- 查看 / 管理客户语料：看为该客户上传的说话风格语料，本 Tab 只做展示与跳转，不直接扣费。

（互动记录 Tab）
- 查看互动记录：看 AI 助手里对该客户做过的操作记录。免费。

（诊断记录 Tab）
- 开始第一次诊断 / 一键复测：跳到诊断页发起 GEO 诊断。计费见用户常问。
- 点某条诊断记录：打开该诊断报告。免费。

## 常见异常
- 列表空空的、「还没有客户」 → 普通用户通常没有下级客户，本页对你一般为空；先点「添加客户」创建。
- 添加客户提示「请输入客户名称」 → 客户名称必填。
- 搜索不到某个客户 → 可能被「隐藏测试客户」开关过滤了（关掉再看），或客户已被软删除（在回收站），或搜索词没匹配到名称/行业。
- 「润色」按钮是灰的 → 该字段当前为空，先填内容再润色。
- 深度行业解析显示「超时待重试」 → 上次任务跑超过 15 分钟没回，点「重试」重新发起（会再次扣费，上次超时已退）。
- 深度行业解析显示「解析失败（已退费）」 → 这次没成功，算力已原路退回，可再点「重试」。
- 「顾问版」模式点不了、提示要先建好客户 → 顾问版要读客户知识库，需在客户详情页内使用且先建好客户。
- AI 填充 / 润色 / 深度解析报算力不足 → 充值后重试。
- 删错了客户 → 去回收站 7 天内恢复。

## 用户常问
- 我的客户页面是干什么的？ → 这是管理你服务的客户档案的工作台：看每个客户阶段、GEO 资料评分、风险、完整度，可新建/编辑/搜索/切换客户。点「打开客户」进详情页，按 Tab 看基本信息、知识库、IP 人设、内容记录、诊断记录、语料库、互动记录，并能用 AI 补全、润色、深度解析、发起诊断。普通用户通常没有下级客户，本页对你一般是空的。
- 列表是空的、提示「还没有客户」怎么办？ → 普通用户通常没有下级客户，本页对你正常为空；先点「添加客户」创建。
- 添加客户怎么填？ → 客户名称必填（留空会提示），行业从下拉选或选「其他(自定义)」手填，城市可填可不填，填完点「添加」。创建免费，建好后自动跳进客户详情页。
- 添加客户会扣费吗？ → 不会。新建、编辑保存、软删除、搜索、切换、打开客户这些列表操作全部免费。
- 客户详情页有哪些 Tab？ → 基本信息、知识库、IP 人设、内容记录、诊断记录、语料库、互动记录。基本信息填客户资料；知识库放行业解析和客户资料文件；IP 人设看客户画像；内容记录看生成过的文案；诊断记录看体检历史；语料库看上传的说话风格语料；互动记录看 AI 助手里的操作记录。
- 删除的客户怎么恢复？ → 软删除后 7 天内可在回收站恢复。
- 搜索不到某个客户怎么办？ → 可能被「隐藏测试客户」开关过滤了（关掉再看），或客户已被软删除（在回收站），或搜索词没匹配到名称/行业。
- 快速模式和顾问版有什么区别？ → 快速模式输入公司名联网搜索、或粘贴资料让 AI 提取，快速补全基本信息；顾问版选一位 AI 顾问、读取该客户已上传的知识库做更深的结构化营销资料填充，能填更多字段。
- 字段润色怎么用？ → 点字段旁「润色」按钮，AI 润色这一个字段，点后弹对比框让你选保留原文还是润色版；字段为空时不可点；选了润色版还要再点「保存」才真正写入。系统不支持一键全部润色，只能逐字段润。
- 深度行业解析要多久？ → AI 联网搜集行业知识，系统处理约 3-8 分钟。过程中可以切走不影响，回来自动更新进度；失败或超时自动原路退费。
- 写作资料确认卡里的「生成确认链」「AI整理资料」扣费吗？ → 不扣。整理资料、生成/重发确认链、复制话术都是免费操作。
- 上传客户资料文件会扣费吗？ → 不会，上传和删除资料文件免费。这份资料会被诊断、报价、写作共用。
- 快速填充 / 顾问版填充各扣多少算力？ [仅服务商] → 代填客户资料时两档都按当前目录价扣算力，顾问版（读客户知识库做更精准深度填充）比快速模式贵；具体数目以点填充前确认页显示的为准。
- 字段润色扣多少算力？ [仅服务商] → 代填客户单字段润色扣算力（数目以点润色前显示的为准）。
- 深度行业解析扣多少算力？ [仅服务商] → 为客户做深度行业解析按当前目录价扣算力（数目以发起前确认页为准），失败/超时自动原路退费。
- 在本页给客户做诊断扣多少算力？ [仅服务商] → 在诊断记录 Tab 或「更多客户动作」里发起，会跳到诊断页：为客户做基础 GEO 诊断扣算力（数目以发起前确认页为准），套餐含 8 道自定义检测问题，超出部分每题另加算力（加多少以确认页为准），诊断失败退算力。
- 批量升级是什么？ [仅服务商] → 列表里有资料完整度低于 80 分的客户时，顶部出现黄色「批量升级」入口（服务商批量经营动作）。点开后可勾选要升级的客户，AI 读取每个客户知识库批量补齐资料，每个客户按当前目录价扣算力，约 30 秒一个，同时跑 3 个，某个客户失败会自动跳过、不影响其他，弹窗会显示总预估扣费和每个客户的成功/失败结果。
- 普通服务商能看到其他服务商的客户吗？ [仅服务商] → 不能。普通服务商只看到自己创建的客户。
- 客户挂在谁名下、客户分成怎么算、客户怎么绑定？ [仅服务商] → 客户归属、绑定与分成口径属服务商范畴，普通用户不可知。

## 流程
1. 进入「我的客户」看客户列表
2. 点「添加客户」填客户名称创建新客户
3. 点「打开客户」进入详情页
4. 在「基本信息」Tab 手动填或用 AI 智能填充（快速 / 顾问版）补全资料，必要时逐字段「润色」，点「保存」
5. 在「知识库」Tab 上传客户资料文件、做「深度行业解析」积累行业知识，整理写作资料并生成确认链发客户
6. 在「诊断记录」Tab 或「更多客户动作」里发起 GEO 诊断
