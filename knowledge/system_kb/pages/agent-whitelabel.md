## 用途
服务商配置对外展示的品牌信息，让客户看到的是服务商自己的品牌而不是平台品牌。

## 字段
- 公司名称（必填）：客户侧展示的公司名，为空时保存按钮不可点。
- Logo URL（可选）：品牌 Logo 地址，建议 200x200px 的 PNG/JPG。
- 品牌主色（可选）：HEX 颜色，取色器加文本框双控，默认 #6CBE1E。
- 联系人（可选）：客户侧页脚展示的联系人。
- 联系电话（可选）：客户侧页脚展示的电话。
- 微信号（可选）：客户侧页脚展示的微信。
- 联系邮箱（可选）：客户侧页脚展示的邮箱。
- 品牌标语（可选）：Logo 旁的副标题文案。
- 产品名（可选）：仅 OEM 档显示，用作浏览器标签/后台标题，如"XX 营销云"。
- Favicon URL（可选）：仅 OEM 档显示，浏览器标签小图标。
- 白标范围表（可选）：标题"开通后哪些页面变成你的品牌"的卡片，6 行勾叉列出各页面开通后是否变成你的品牌——报价单、诊断报告、客户门户、物料这四项开通生效后都换成你的品牌；服务商后台只有"含后台"（OEM）档才换；邀请页暂不变。开通生效前显示"开通后会换/补资料后生效"等未生效状态，不误导。
- 客户看到的样子（可选）：右侧实时预览卡，把你填的公司名、Logo、主色、联系方式、标语实时渲染成客户在报价单/诊断报告/客户门户/充值页顶部看到的样子，边填边变、不用保存就能看效果；OEM 档还多一块"你自己的后台浏览器标签"预览，显示产品名和小图标。

## 按钮
- 保存：保存所有品牌字段并即时生效到客户侧；公司名称为空时不可点。

## 常见异常
- 保存按钮点不了 → 公司名称必填，先填公司名称。
- 提示某些字段仅管理员可设置 → 授权档位/状态由管理员控制，服务商不能自己改，只能改品牌字段。
- 页面显示"白标尚未开通" → 还没授权，联系平台管理员申请开通。
- 页面显示"白标已暂停"、资料变只读 → 白标被暂停，联系平台恢复。

## 用户常问
- 白标是什么，能改哪些地方？ → 白标就是让客户看到的是你自己的品牌而不是 OmniRank 平台品牌。可改公司名称、Logo、品牌主色、联系人/电话/微信/邮箱、品牌标语；OEM 档还能额外改产品名和浏览器标签小图标（Favicon）。
- 怎么开通白标？ → 联系平台管理员申请，管理员审核授权后本页才能编辑；未授权时页面显示"白标尚未开通"引导页。
- 白标会影响我给客户的价格吗？ → 不影响。本页只管品牌外观，不含任何价格或加价系数，价格在"销售定价"和个人设置里设。
- external_only 和 OEM 有什么区别？ → external_only 只换客户可见侧（报价单/诊断报告/客户门户/充值页）的品牌；OEM 在此基础上额外换你自己后台的浏览器标签和图标（产品名、Favicon）。
- 白标被暂停了怎么办？ → 页面显示红色"白标已暂停"、资料变只读时，说明白标被平台暂停了，联系平台恢复。

## 截图问答指引
- 截图有"公司名称""Logo URL""品牌主色"取色器、联系方式、品牌标语等表单 → 这是对外品牌(白标)页，告诉服务商这里只改品牌外观、不含价格；公司名称为空时保存按钮点不了。
- 截图额外出现"产品名""Favicon URL"字段 → 这是 OEM 档，比 external_only 多换服务商自己后台的浏览器标签和图标。
- 截图显示"白标尚未开通"引导页、不可编辑 → 还没授权，引导联系平台管理员申请开通。
- 截图黄色提示"已授权 · 待激活"或绿色"白标已生效" → 已可编辑，填完品牌字段点保存即生效到客户侧。
- 截图红色"白标已暂停"、资料只读 → 白标被暂停，引导联系平台恢复。
- 截图保存按钮点不了 → 公司名称必填，先填公司名称。
- 截图有"开通后哪些页面变成你的品牌"卡片、6 行带勾/锁/时钟图标（报价单/诊断报告/客户门户/物料/服务商后台/邀请页）→ 这是白标范围表，定位到对外品牌(白标)页；告诉服务商报价单/诊断报告/客户门户/物料这四项开通生效后变成你的品牌，服务商后台只有"含后台"（OEM）档才换，邀请页暂不变；绿勾=已生效、锁/时钟=未生效。
- 截图右侧有"客户看到的样子"卡片、显示一个带 Logo/公司名/报价单标签的预览块 → 这是客户侧实时预览，定位到对外品牌(白标)页；告诉服务商这是边填边变的预览，客户在报价单/报告/门户/充值页看到的就是这个样子；若预览里还有"你自己的后台浏览器标签"小块，说明是 OEM 档。

## 流程
1. 联系平台管理员申请开通白标（管理员授权后本页才可编辑）。
2. 填写公司名称（必填）、Logo、主色、联系方式、标语等。
3. OEM 档再填产品名和 Favicon。
4. 点"保存"，客户侧报价单/报告/门户/充值页立即显示你的品牌。

## 状态
- external_only：只换客户可见侧（报价单/诊断报告/客户门户/充值页）。OEM：在此基础上额外换服务商自己后台的浏览器标签和图标。
- 未授权：显示"白标尚未开通"引导页，不可编辑。
- 已授权待激活：黄色提示"已授权 · 待激活"，可编辑。
- 已生效：绿色提示"白标已生效"，可编辑。
- 已暂停：红色提示"白标已暂停"，只读。
- 本页只管品牌外观，不含任何价格/系数（价格在销售定价和个人设置里）。
- 编辑时右侧有客户侧实时预览；查看和保存都不扣费。
