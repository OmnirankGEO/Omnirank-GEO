## 用途
服务商管理自己的算力库存（弹药库）：先用人民币向平台预付进货，把算力充进自己的库存；再把库存里的算力划拨给自己名下的客户使用。库存分两池——充值库存和赠送库存，进货、划拨、撤回都在这一页操作，所有变动都进流水。整页都是服务商自己的库存动作，不涉及客户付款。

## 字段
- 充值库存（可选）：进货付费得到的库存，卡片标注"全功能可用"，工具和发布都能用。划拨给客户的工具算力、发布算力都从这里扣。
- 赠送库存（可选）：进货时按比例赠送（或平台赠送）得到的库存，卡片标注"不可用于发布"，只能用于工具类功能。划拨给客户的赠送算力从这里扣。
- 预警级别（可选）：按"当前剩余库存 ÷ 累计进货"的比例给余量提示。剩余大于 30% 显示"正常"；30% 及以下显示"<30%"；10% 及以下显示"<10%"；用尽显示"0%"并带警告图标。还没进过货时显示"正常"。
- 累计进货 / 累计划拨（可选）：预警卡下方的小字，分别是历史总进货算力和总划拨算力，只读统计。
- 客户编号（必填）：划拨/撤回弹窗里填客户的用户编号（一串数字 ID，不是客户品牌名）。
- 工具算力（划拨/撤回弹窗，可选）：给客户的工具使用算力；划拨时从你的充值库存扣，撤回时回到你的充值库存。
- 发布算力（划拨/撤回弹窗，可选）：给客户的发布算力；划拨时从你的充值库存扣，撤回时回到你的充值库存。
- 赠送算力（划拨/撤回弹窗，可选）：给客户的赠品算力；划拨时从你的赠送库存扣，撤回时回到你的赠送库存。
- 备注 / 原因（可选）：划拨写"备注"、撤回写"原因"，都是说明文字，会记进流水。

## 按钮
- 刷新：重新拉取库存余额、进货档位、流水，不动账。
- 立即进货（点档位卡片）：创建一笔预付进货订单并弹出支付二维码/链接；下单时还没入库存，只有支付成功后才把充值库存和赠送库存入到你的库存里。
- 划拨给客户（线下划拨 Tab）：打开划拨弹窗，填客户编号和工具/发布/赠送算力后点"确认划拨"，从你的库存扣、同步加进客户的算力钱包。线下已经收过客户的钱时用这个，平台不代收、不记你的收入流水。
- 确认划拨（划拨弹窗内）：提交本次划拨；客户编号留空或填 0 会拦下不放行。
- 撤回算力（线下划拨 Tab）：打开撤回弹窗，填客户编号和各项要撤的算力，点"确认撤回"，把客户没用掉的部分回退到你的库存。
- 确认撤回（撤回弹窗内）：提交本次撤回；实际撤回量自动取小值，可能比你填的少。
- Tab 切换（进货 / 线下划拨 / 流水）：只切换视图，不动账。

## 常见异常
- 库存不足无法划拨（充值或赠送库存不够本次划拨量） → 先进货补库存，或减少本次划拨算力。
- 划拨没填任何算力（工具/发布/赠送都为 0） → 至少填一项大于 0 才能划拨。
- 划拨/撤回算力填了负数 → 必须填非负数，要划拨就填大于 0 的整数。
- 客户编号没填或填 0 → 提示客户编号必填，补上客户的用户编号（数字 ID，不是品牌名）。
- 填的客户已经绑定了别的服务商 → 不允许划拨给别人名下的客户，确认客户编号；如果是还没绑过任何服务商的新客户，划拨时会自动绑到你名下，可以正常划。
- 撤回撤不全 / 撤回量比填的少 → 已经被客户消费掉的部分撤不回，系统按客户当前剩余算力自动取小值，只回退还没用掉的部分。
- 微信内进货支付调不起来 → 微信内下单会自动切换支付方式，提示用电脑扫码或外部浏览器完成支付；仍不行就刷新换 PC 重新下单。
- 进货下单后库存没变 → 下单只是建了待支付订单，要支付成功才入账，没付或没付成功不会入库。

## 用户常问
- 我的库存这页是干什么的？ → 这是你管理自己算力库存（弹药库）的地方：先用人民币向平台进货把算力充进库存，再把库存算力划拨给自己名下的客户用。进货、划拨、撤回、查流水都在这一页。
- 进货的算力怎么换算？三个档位各送多少？ → 换算系数和各档赠送比例都由平台后台配置、会调整，**以进货页面下单时显示的数字为准**。页面上每个档位卡片都会写清这一档到账多少充值库存、附赠多少赠送库存，下单前核对那里就行。
- 充值库存和赠送库存有什么区别？ → 充值库存是你花钱进货得到的，工具和发布功能都能用；赠送库存是进货赠送或平台赠送的，只能用于工具类功能，不能用于发布。划拨时工具算力、发布算力从充值库存扣，赠送算力从赠送库存扣。
- 怎么给客户开算力？ → 线下收过客户的钱后，进"线下划拨"Tab 点"划拨给客户"，填客户编号（客户的用户数字 ID，不是品牌名）和工具/发布/赠送算力，至少填一项，点"确认划拨"，就从你的库存扣、同步加进客户的算力钱包。这条路平台不代收钱、不记你的收入。
- 客户编号填错或填成品牌名会怎样？ → 客户编号要填客户的用户数字 ID。如果填的客户已经绑了别的服务商，会被拦下；如果是还没绑过服务商的新客户，划拨时会自动把他绑到你名下。
- 撤回算力能撤多少？ → 只能撤客户还没用掉的部分。系统会按你填的撤回量和客户当前剩余算力自动取小值，已经被客户消费掉的撤不回，所以实际撤回量可能比你填的少。撤回成功提示里会说"严格按未消费上限"。
- 撤回的算力回到哪里？ → 工具算力和发布算力撤回后回到你的充值库存，赠送算力撤回后回到你的赠送库存，双侧余额当场更新。
- 进货下单了没扣到库存怎么回事？ → 下单时只建了待支付订单，还没入库存，要支付成功后算力才入到你的充值库存和赠送库存；没付款或没付成功就不入账，付了没到刷新一下再看。
- 进货支付走的哪种方式？ → 系统按你的设备自动选：电脑上出扫码二维码，手机浏览器出 H5 支付，微信里会自动换成可调起的支付方式。每 3 秒自动检查一次支付状态，付成功会自动提示并刷新库存。

## 流程
1. 进"进货"Tab，点 ¥1000 / ¥5000 / ¥10000 任一档位卡片。
2. 弹出支付二维码或支付链接，完成支付，系统每 3 秒自动查状态，成功后充值库存和赠送库存自动入你的库存。
3. 线下收过客户的钱后，进"线下划拨"Tab 点"划拨给客户"，填客户编号和工具/发布/赠送算力（至少一项），点"确认划拨"。
4. 需要收回客户没用完的算力时，点"撤回算力"，填客户编号和各项要撤的量，点"确认撤回"，系统按未消费余额自动取小值回退。
5. 在"流水"Tab 查看进货、自动补库存、划拨、撤回等全部记录。

## 状态
- 进货换算：换算系数与三档赠送比例均为平台后台可调的系统系数，**页面下单时实时显示**，本文不记具体数字。
- 预警级别按"当前剩余（充值+赠送）÷ 累计进货"算：>30% 正常，≤30% / ≤10% / 用尽分别提示 <30% / <10% / 0%（带警告图标）；未进货时显示正常。
- 划拨：工具算力、发布算力从充值库存扣，赠送算力从赠送库存扣；库存不够会被拦下不放行。给未绑服务商的新客户划拨会自动把他绑到你名下，给已绑别的服务商的客户会被拒。
- 撤回：实际撤回量 = 取小值（你填的量、客户当前剩余算力），已被客户消费的撤不回；工具/发布回充值库存，赠送回赠送库存，双侧余额当场更新。
- 空态：流水无记录时显示"暂无库存记录"。
- 查看、切 Tab、进货下单都不扣库存，只有进货支付成功才入账；划拨/撤回成功后双侧余额即时更新。
