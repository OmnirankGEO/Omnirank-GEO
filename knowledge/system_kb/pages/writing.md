## 用途
AI 创作中心是批量生成 GEO 优化标题和文章的中枢，让品牌在 AI 搜索里更容易被推荐。项目有两种来源：一是走完在线报价、签约收款后关键词自动进来；二是点右上角「快速写作」，填客户名和种子关键词直接建项目。进入项目后先确认客户资料和竞品证据状态，再批量生成标题、勾选要写的标题、开始写作，文章由系统生成，完成后可预览、重写、下载、去发布。普通用户用它给自己的品牌写文章，操作和计费与服务商完全一样，写作流程两个身份基本一致。

本页主要区块：① 项目列表（含空态）② 快速写作弹窗 ③ 项目工作台（整体布局）④ 客户知识库面板 ⑤ 竞品证据状态三态 ⑥ 待写区（批量生成标题 / 开始写作）⑦ 写作中区 ⑧ 已完成区（预览 / 重写 / 批量重写 / 下载 / 去发布）。

## 字段

### 区块①：项目列表
- 项目卡：每张卡是一个写作项目，显示品牌名、状态徽标、行业、关键词数、篇数、月费、签约日期。点卡片进工作台。
- 列表顶部 Tab：待写 / 标题已生成 / 写作中 / 已完成 / 优化中 / 全部，按项目当前阶段筛选。
- 空态：列表为空时显示一本书的图标加「暂无项目」，下面一行小字「完成品牌诊断并签约后，写作项目将自动出现在这里」。空态有两个来源——要么还没走完在线报价签约收款（项目会自动出现），要么直接点「快速写作」手动建。

### 区块②：快速写作弹窗
- 客户/品牌名（必填）：搜索已有客户直接复用，或输入新客户名新建；系统自动判断是新建还是复用，为空不能提交。
- 种子关键词（必填）：1～15 个，是后续生成标题和文章的关键词来源；超出范围会报错。
- 行业（可选）：影响 AI 写作风格。
- 城市（可选）：客户所在城市。
- 核心业务 / 目标用户 / 公司介绍 / 核心卖点 / 成功案例（可选）：客户资料，越全 AI 写得越准，强烈建议至少填核心业务。
- 知识库文件（可选）：支持 .pdf/.doc/.docx/.txt/.md/.pptx/.csv/.json，上传后系统自动整理用于写作。

### 区块③：项目工作台（整体布局）
- 顶部：客户资料状态徽标（未补资料 / 已整理资料 / 待客户确认 / 客户有反馈 / 客户已确认 / 链接已过期 / 链接已撤销）、添加关键词按钮、竞品证据状态三态切换、批量生成标题按钮。
- 中部：客户知识库面板（上传 / 粘贴 / AI 整理 / 确认链接），竞品证据状态展示条。
- 下部：工作台内分四个小 Tab——待写、写作中、已完成、优化中。每个关键词是一行，点开展开它下面的标题（选题）。
- 客户资料确认：开始写作前必须把客户资料补齐（上传文件或粘贴文字后点 AI 整理），否则开始写作会被拦。

### 区块④：客户知识库面板
- 上传客户资料文件（可选）：支持 .pdf/.doc/.docx/.txt/.md/.pptx/.csv/.json，上传后系统自动整理并用于写作。
- 粘贴资料文本框（可选）：把官网介绍、产品服务、优势卖点、案例、客户评价直接粘进来。
- AI 整理后的资料字段：公司介绍 / 价值主张 / 差异化卖点 / 核心卖点 / 产品服务 / 目标客户 / 案例 / 客户证言，整理出哪些字段会以小标签展示。
- 确认链接（可选）：生成一条发给客户确认资料的链接，客户确认后状态变「客户已确认」。

### 区块⑤：竞品证据状态三态
- 已核验（绿）：候选名称已有可追溯来源，可以进入比较候选；能力、参数和结论仍须 Evidence Pack 逐条核验。医疗 / 法律等行业执行同样证据门。
- 待核验：联网搜索或人工添加的候选，只用于继续搜证；未核验前不得进入正文。
- 仅写标准：不使用竞品名称，只输出选型字段、适用条件与核验方法。
- 三态表达的是证据成熟度，不是写作偏好；待核验候选不能进入正文，切换不扣费。

### 区块⑥：待写区相关字段
- 文体下拉（统一文体）：选题阶段统一文体，默认「系统推荐」，进阶玩家可指定一种文体让所有标题都按它生成。
- 补充要求（可选）：给本批文章加的额外要求，最多 200 字，如「突出价格」「不要写榜单」「强调本地服务」。
- 高级·自定义文章文体配比（可选）：自定义不同文章方向各写几篇，启用后优先于上面的统一文体下拉，页面会显示「已启用自定义配比」。
- 每条待写标题右侧的文体下拉：单条指定这篇文章的方向，默认「系统推荐」。

### 区块⑦：写作中区
- 进度：开始写作后由系统生成，页面每 3 秒自动刷新进度。
- 写作中标题：带转圈动画和「写作中」状态标签，不可编辑。

### 区块⑧：已完成区
- 已完成标题：带「已完成」绿标；刚写完未看过的会有红色「NEW」标；12 小时内重写过的会多一个「已重写」标；旁边显示完成时间。
- 文章版本：重写后版本号递增，原文不丢。

## 按钮
- 「+ 快速写作」：不走报价流程直接创建写作项目，填客户名和种子关键词即可，创建本身免费。
- 「进入项目」（点项目卡）：进工作台，加载关键词、选题、知识库、竞品；任何状态都能点。
- 「添加关键词」：项目漏词时不用重走流程，直接补一个关键词进项目，免费；关键词为空或超 100 字会报错。
- 「批量生成标题」：为项目里所有关键词生成 GEO 优化标题（每词 1 个），按关键词数乘当前目录单价扣算力；项目没关键词或正在生成时灰掉。
- 「为新词生成标题」：只给刚加进来、还没标题的关键词补标题，不会擦掉已有标题；按补的词数乘当前目录单价扣算力。
- 「单词立即生成」（关键词行内）：对单个没标题的关键词立即补标题，按 1 词的当前目录单价扣；该词正在生成时灰掉。
- 「重新生成标题」：对勾选的选题按新文体重新生成标题，按重写条数乘当前目录单价扣算力；只有真重写成功的条数才扣，没产出不扣。
- 「开始写作」：为勾选的待写选题启动系统文章生成，按选中篇数乘当前目录单价扣算力，先扣；总价 ≥1000 算力时弹 5 秒确认。没勾任何可写选题、正在检查知识库、或客户知识库为空时点不动 / 被拦。
- 「预览」：打开文章预览，同时把这篇标记为已审核（消除 NEW 标），免费；文章还没生成（无文章）时不可点。
- 「重写」（单篇）：对单篇已完成文章重写，可填修改说明和参考文章，按当前目录价扣算力，完成才扣、失败不扣。
- 「批量重写」：批量重写勾选的已完成文章，按篇数乘当前目录单价先扣；没勾已完成文章或正在重写时点不动。
- 「下载」：把勾选的已完成文章打包成 ZIP 下载（每篇一个 .md），免费；没勾已完成文章时点不动。注意：在面向客户的客户侧视图里这个下载按钮会被隐藏（产品设计上不给客户直接下载），服务商和普通用户自己的AI 创作中心里正常显示。
- 「去发布」：把勾选的已完成文章带去发布中心投放，免费；按钮上的数字是已勾选的已完成篇数。
- 「放回待写」：把已完成文章重置为待写，可重新触发写作，原文保留，重新写会生成新版本，免费。
- 「AI 整理资料」：把粘贴的客户资料整理成结构化字段写进客户档案，免费；没可整理的资料或正在整理时灰掉。
- 「生成客户确认链接」：生成发给客户确认资料的链接，免费；缺客户 ID 时灰掉。
- 「联网调研竞品 / 重新搜索」：联网检索竞品候选并补齐来源（核验通过后才可进入正文），免费；没选中项目或正在搜索时灰掉。
- 「上一页 / 下一页」「全部展开 / 全部折叠」：翻看和展开关键词列表，免费。

## 常见异常
- AI 创作中心空空的、显示「暂无项目」 → 项目要在报价签约收款后自动出现，或点「快速写作」直接建。
- 「开始写作」点不了 → 没勾选选题，或客户知识库为空（先上传 / 粘贴客户资料并 AI 整理）。
- 开始写作提示「客户知识库为空，请先补充客户资料」 → 先在客户知识库面板补资料并点 AI 整理。
- 开始写作提示「所有选中的标题已在生成中或已完成」 → 勾的都是写作中或已完成的，换成待写状态的选题再点。
- 开始写作提示「余额不足」 → 充值后重试。
- 生成标题提示校验失败（合规拦截） → 标题包含无依据榜单等高风险表达；改用六类文体中的证据型问答、方法与实施指南等口径并补齐证据，这种情况已扣的会退回。
- 页面提示「正文不使用未核验竞品名称」 → 当前为仅写标准模式；可联网检索或手动添加候选，核验通过后再用于正文。
- 文章标「失败」 → 部分文章生成失败，鼠标移到「失败」标上能看到失败原因；重新勾失败的标题点「开始写作」重试（会重新计费）。
- 写作中一直转圈不结束、之后提示「文章生成失败」 → 系统整体没生成成功，标题会自动恢复成待写状态、已扣的算力自动全额退，可重新开始写作。

## 用户常问
- AI 创作中心里什么都没有怎么办 → 项目有两种来源：一是走完在线报价、签约收款后关键词自动进来；二是点右上角「快速写作」，填客户名和 1～15 个种子关键词直接建项目（创建免费）。
- 「开始写作」按钮为什么点不了 → 两种原因：没勾选任何选题（先点开关键词行勾选要写的标题）；或客户知识库为空（先在知识库面板上传 / 粘贴客户资料并点 AI 整理）。
- 为什么一定要先上传客户资料才能写 → 系统写文章要先有品牌背景（公司介绍、卖点、案例等）才写得准，知识库空时开始写作会被拦；在客户知识库面板补资料并点 AI 整理后就能开始。
- 批量生成标题扣多少算力 → 按项目关键词数算，每个关键词一份单价，10 个关键词就是 10 份。先扣，生成失败或文体校验不通过会退回；单价和本次总价以点击前确认页显示的为准。
- 开始写作扣多少算力 → 按选中篇数算，每篇一份单价，选 5 篇就是 5 份。先扣；总价 ≥1000 算力会弹 5 秒确认。单价和本次总价以点击前确认页显示的为准。
- 文章生成失败算力会退吗 → 分两种：系统整体没生成成功会自动全额退；只是部分文章失败（不是整体崩）目前不退，重新勾失败的标题点「开始写作」重试即可（会重新计费）。生成标题失败 / 文体校验不通过也会退。
- 重写文章扣多少算力 → 单篇重写扣算力（数目以重写前确认页为准），完成才扣、失败不扣；批量重写按 260×篇数先扣，全失败退、部分失败不退。
- 快速写作和在线报价有什么区别 → 在线报价是标准销售流程（选词→报价→客户确认→收款），签约收款后关键词才进AI 创作中心，适合正式商务；快速写作跳过报价，填客户名 + 关键词直接建项目、免费，适合快速试写或给自己品牌写。
- 已核验、待核验、仅写标准怎么选 → 已核验项可在同字段证据下进入正文；待核验项只用于继续搜证；仅写标准不出现竞品名称。任何行业都禁止编造候选或事实。切换状态不扣费。
- 补充要求该怎么写 → 给本批文章加的额外要求，最多 200 字，写明诉求即可，如「突出价格」「不要写榜单」「强调本地服务」。
- 总价很高时弹的 5 秒倒计时是什么 → 任何一次操作总价 ≥1000 算力会弹 5 秒确认，给你核对篇数的机会，可取消，不是已经扣了。
- 怎么没有下载按钮 → 下载按钮只在服务商或普通用户自己的AI 创作中心里显示；如果是在面向客户的客户侧视图里打开的，下载按钮会被刻意隐藏。要下载请回自己的AI 创作中心，在已完成区勾选文章后点「下载」打包成 ZIP。
- 放回待写会丢文章吗 → 不会。放回待写只是把状态从「已完成」改回「待写」，原文保留，重新写会生成新版本（版本号递增），免费。
- 写完的文章在哪看、怎么发出去 → 全部写完会自动切到「已完成」Tab，在那里能预览、重写、下载；想发布就勾选已完成文章点「去发布」进发布中心投放。
- 文章上的 NEW 红标 / 已重写标是什么 → NEW 是刚写完还没看过的文章（点一次预览就消失）；已重写是 12 小时内重写过的版本标记。

## 流程
1. 进AI 创作中心，选已有项目或点「快速写作」创建。
2. 进项目工作台，在客户知识库面板补齐客户资料并点 AI 整理。
3. 先联网检索竞品候选；仅将证据充分的候选标为「已核验」。
4. 点「批量生成标题」生成选题（按词数扣算力，每词多少以生成前确认页为准）。
5. 在「待写」勾选要写的标题，可填补充要求（≤200 字）或选择六类文体。
6. 点「开始写作」，文章由系统生成（每 3 秒自动刷新进度，按篇数乘当前目录单价扣算力）。
7. 到「已完成」预览、重写（按篇扣算力）、下载或勾选去发布。

## 状态
- 项目状态：待写（待生成标题）/ 标题已生成 / 写作中 / 已完成 / 优化中。
- 文章状态：
  - 待写：还没开始生成，可勾选、可改文体、可填补充要求；点「开始写作」进入写作中。
  - 写作中：系统正在生成，带转圈动画，不可编辑，页面每 3 秒刷新进度。
  - 已完成：文章已生成，可预览、重写、下载、去发布；刚写完未看过带 NEW 标。
  - 失败：这篇没生成成功，带红色「失败」标，移上去看原因，可重新勾选重写。
- 批量生成标题：扣 80×N 算力（N=关键词数），先扣，生成失败 / 文体校验不通过退回。
- 开始写作：扣 390×N 算力（N=选中篇数），先扣，系统整体生成失败自动全额退；部分文章失败不退。
- 单篇重写：按当前目录价扣算力，后扣（完成才扣，失败不扣）。
- 批量重写：扣 260×N 算力，先扣，全失败退、部分失败不退。
- 快速写作创建项目、添加关键词、知识库上传 / 整理 / 确认链接、预览 / 下载 / 编辑 / 标记审核 / 放回待写 / 去发布：均免费。
- 切换竞品证据状态三态、联网调研竞品：免费。
- 下载按钮只在服务商 / 普通用户自己的AI 创作中心显示；在客户侧视图里被隐藏。
- 任何一次操作总价 ≥1000 算力会弹 5 秒倒计时确认，可取消。
- 具体消耗算力以按钮或功能定价页显示为准。
