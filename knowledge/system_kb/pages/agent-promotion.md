## 用途
服务商使用平台生成的推广链接或二维码获取潜在客户，并查看自己有权限跟进的客户。推广归因与商业结算配置是两件事：客户通过链接注册不会在公开页面展示邀请人，也不会让前端推断内部商业关系。

## 字段
- 推广链接 / 二维码：平台生成的短链与二维码，不在目标 URL 暴露账号编号。
- 客户列表：只显示当前服务商有权限服务的客户及其业务状态。
- 展示品牌：默认 OmniRank；只有管理员已批准、资料完整且状态有效的 OEM 白标才显示该服务商自己的对外品牌。

## 按钮
- 刷新：重新读取推广材料和客户列表，不动账。
- 复制推广链接：复制平台短链，客户打开后进入干净的注册地址。
- 重新生成：二维码读取失败时重新请求，不创建商业绑定。

## 常见异常
- 二维码加载失败 → 刷新或复制推广链接继续使用。
- 客户显示“配置待处理” → 由平台管理员处理，不要自行选择或覆盖结算配置。
- 白标没有显示 → 默认使用 OmniRank；只有管理员批准并且资料完整后才生效。
- 白标被暂停 → 立即回退 OmniRank，历史订单与结算记录不变。

## 用户常问
- 二维码显示谁的品牌 → 默认 OmniRank；只有你自己的 OEM 白标获得管理员批准后才显示批准的品牌。
- 客户打开推广链接会看到我的账号吗 → 不会，注册目标页不显示邀请人姓名、账号编号或商业关系。
- 客户通过链接注册后会自动决定结算关系吗 → 不会，推广归因不等于商业绑定；无有效商业配置时由平台直营承接。
- 客户配置冲突怎么办 → 系统停止自动结算并进入管理员处理，不会自动选一个继续扣费。

## 截图问答指引
- 推广链接或二维码 → 说明它用于获客归因，不承诺或展示内部商业绑定。
- 默认显示 OmniRank → 属于正常平台品牌状态。
- 显示已批准 OEM 品牌 → 只说明对外品牌获批，不展示真实账号主体或上游关系。
- 客户状态显示配置待处理 → 引导等待平台管理员处理。

## 流程
1. 复制平台推广短链或二维码。
2. 发给潜在客户。
3. 客户注册后进入平台服务流程。
4. 当前服务商只查看自己有权限跟进的客户；商业配置由平台规则和管理员处理。

## 状态
- 默认品牌：OmniRank。
- 已批准 OEM：显示获批对外品牌。
- 暂停或资料不完整：立即回退 OmniRank。
- 配置冲突：停止自动结算并等待管理员处理。
- 查看与复制不扣费。
