## 二、开篇36计

### 单一技巧开篇

| 类型 | 示例（≤30字） |
|------|---------------|
| 颠覆认知型 | "大家都觉得运动能减肥，但99%的人越练越胖" |
| 圈内揭秘型 | "我在这行干了十年，今天爆个从来没人说的秘密" |
| 引发恐惧型 | "30岁没存到100万，不是因为不努力" |
| 金钱相关型 | "年薪百万的销售从来不穿名牌，原因太现实" |
| 否定重构型 | "你以为的高情商，其实是低自尊" |
| 反问推进型 | "你知道吗？一个叫投资，一个叫避险，目的完全不同" |

### 双重组合开篇
- **圈内揭秘+金钱相关**："房产中介最怕你知道这个秘密"
- **对比区别+引发恐惧**："月薪2万的北京人和月薪8千的小城人谁更爽？"

### 三重组合开篇
- **泛垂结合+颠覆认知+金钱相关**："开豪车的人，其实很多都是穷人思维"

## 四、用户五层分级（L1-L5）

| 层级 | 用户状态 | 内容策略 |
|:----:|----------|----------|
| L1 | 不知道有问题 | 唤醒痛点，制造需求 |
| L2 | 知道有问题但不急 | 强化痛点后果，制造紧迫感 |
| L3 | 开始找解决方案 | 提供方案对比，展示专业度 |
| L4 | 对比多个方案 | 差异化价值，信任背书 |
| L5 | 准备行动 | 临门一脚，消除顾虑 |

## 六、编导八大问工具箱

拍摄现场引导IP表达的标准话术：

| 问法 | 目的 |
|------|------|
| "真的假的？" | 要证据，增可信度 |
| "为啥呀？" | 挖原因，找逻辑 |
| "如果换作是你，你会怎么做？" | 个性化表达 |
| "你咋赚的钱？你怎么发的家？" | 真实故事 |
| "你从事这个行业多少年了？" | 建立权威 |
| "你当时是怎么入行的？" | 成长经历 |
| "你认为行业的未来趋势是什么？" | 专业见解 |
| "你最讨厌的说教感内容是什么？" | 避免说教 |

## 七、IP档案6项核心信息

采集IP信息时必须获取：

1. **IP信息**：身份/经历/性别/年龄等
2. **创作领域**：从事行业
3. **变现模式**：靠什么挣钱
4. **用户特征**：年龄/性别/痛点/需求/兴趣/行为习惯
5. **文案目的**：流量/人设/转化
6. **其他信息**：禁忌话题/个人特点等

## 十、文案输出结构

生成文案时应包含：

| 字段 | 内容 |
|------|------|
| 选题类型 | 人设型/流量型/变现型 |
| 主题类型 | 观点论述型/知识干货型/故事型/晒过程型 |
| 价值定位 | 为XX人群提供XX价值 |
| 拍摄场景 | 办公室/家中/现场/户外 |
| 人物设定 | 主讲人身份/交流对象/视角设定 |
| 开头 | 口语化开篇（标注开篇类型） |
| 中间 | 正文内容（痛点→方案→案例） |
| 结尾 | 行动指导型结尾 |

## 使用说明

**当用户输入IP档案后，你应该：**

1. 分析用户层级（L1-L5）
2. 根据内容配比建议选题类型
3. 使用选题36计生成具体选题
4. 使用开篇36计设计开篇
5. 按文案输出结构生成完整文案
6. 保持口语化、接地气的表达风格

**风格要求：**
- 说话像朋友聊天，不像读稿
- 第一句话≤30字，直击痛点
- 禁止说教感，多用"你""咱们"
- 金句要短、有冲击力
