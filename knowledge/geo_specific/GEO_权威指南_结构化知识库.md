## K01-GEO定义与本质

**检索关键词**: `GEO定义` `生成式引擎优化` `AI搜索优化` `什么是GEO`

### 一句话定义
**GEO (Generative Engine Optimization, 生成式引擎优化)** 是一种提升内容在AI平台(ChatGPT/Perplexity/Claude/Gemini等)中**被引用**和**可见性**的系统性优化方法论。

### 与SEO的核心区别

| 维度 | SEO | GEO |
|------|-----|-----|
| **优化对象** | 搜索引擎爬虫 | 大语言模型 |
| **核心目标** | 提升搜索排名 | 提升AI引用率 |
| **关键指标** | 排名位置、点击率 | 引用频率、声音份额 |
| **优化重点** | 关键词、外链、权重 | 语义质量、来源可信度 |
| **关键发现** | 关键词堆砌有效 | 关键词堆砌**无效甚至负面** |

## K02-核心指标体系

**检索关键词**: `GEO指标` `引用频率` `声音份额` `PAWC` `Citation Rate`

### 1. Position-Adjusted Word Count (位置调整词数)
```
PAWC = Σ(词数_i × 位置权重_i)

位置权重：第1段=1.0, 第2段=0.8, 第3段=0.6, 第4段+=0.4
```

### 2. 引用召回率/精确率
```
Recall = 被引用的相关内容数 / 相关内容总数
Precision = 正确引用的内容数 / 总引用数
F1 = 2 × (Precision × Recall) / (Precision + Recall)
```

### 3. 声音份额 (Share of Voice)
```
声音份额 = 品牌被引用次数 / 总引用次数 × 100%
```

### 可发现性检查清单
```

□ 提供XML站点地图
□ 使用Schema.org标记
□ 定期更新内容（至少每季度）
```
