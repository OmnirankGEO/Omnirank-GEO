## 一、适用范围

本政策适用于您通过 OmniRank AI 网站、移动应用、小程序、API 接口等一切形式访问和使用本服务的行为。

## 二、我们收集哪些信息

### 2.1 您主动提供的信息

| 场景 | 收集的信息 |
|------|----------|
| **注册账号** | 手机号、短信验证码、登录密码（加密存储） |
| **完善资料** | 昵称、头像、邮箱（选填）、企业名称（企业用户） |
| **实名认证** | 身份证号、姓名、企业营业执照（仅限提现、开发票场景） |
| **品牌诊断** | 品牌名称、行业、关键词、业务描述、产品信息 |
| **AI 建档** | 业务对话内容、个人创作风格、行业经验描述 |
| **文件上传** | 您主动上传的图片、PDF、音频、视频等 |
| **支付** | 支付金额、支付方式（不存储银行卡完整号码） |

### 2.2 使用服务时自动收集的信息

- **设备信息**：设备型号、操作系统、浏览器类型、IP 地址、MAC 地址、屏幕分辨率
- **日志信息**：访问时间、访问页面、操作记录、功能调用记录、错误日志
- **位置信息**：基于 IP 推断的城市级位置（用于服务优化和合规要求）
- **Cookie 和类似技术**：用于保持登录状态、个性化展示、使用分析

### 2.3 通过第三方获取的信息（需您授权）

- **微信/支付宝**：微信 OpenID、支付宝用户 ID（用于支付和扫码登录）
- **社媒平台**：抖音、小红书等平台的公开视频数据（仅限您主动提交要分析的 URL）

### 2.4 **我们不会收集以下信息**

- 未经您授权的通讯录、通话记录、短信内容
- 未经您授权的地理位置精确坐标
- 您其他平台账号的密码

## 三、我们如何使用您的信息

### 3.1 核心用途

| 用途 | 说明 |
|------|------|
| **提供服务** | 基于您的品牌信息生成 GEO 方案、内容、报告 |
| **账号管理** | 身份认证、密码重置、通知推送 |
| **支付与结算** | 处理充值、消费、提现、开票 |
| **客户服务** | 响应咨询、处理投诉、故障排查 |
| **安全保障** | 识别异常登录、防止欺诈、保护账户安全 |

### 3.2 产品改进

- 基于**匿名化、聚合化**的使用数据分析用户行为，优化产品
- 使用**去标识化**的 AI 生成内容样本训练模型、改进算法
- 具体说明：我们可能使用您的使用数据进行统计分析（如"本月平均生成 10 条脚本的用户是 X%"），但不会在未经您同意的情况下识别到您个人

### 3.3 个性化推荐

- 基于您的行业、使用历史推荐选题、模板、顾问
- 您可以随时在"设置"中关闭个性化推荐

### 3.4 营销通知

- 我们可能通过短信、站内信、邮件发送功能更新、促销活动
- 您可以随时取消订阅营销类通知（功能通知、安全通知不可关闭）

## 四、我们如何共享您的信息

### 4.1 我们不会出售您的个人信息

**平台明确承诺：不会将您的个人信息出售给任何第三方。**

### 4.2 以下情形下我们会共享您的信息

#### 4.2.1 向第三方服务商共享（为提供服务必需）

| 第三方 | 共享的信息 | 用途 |
|--------|-----------|------|
| **境内 LLM 供应商**（阿里通义、DeepSeek、Kimi、字节豆包等） | 您提交的品牌信息、对话内容（去标识化） | 生成 AI 内容 |
| **境外 LLM 供应商**（OpenAI 等，仅在您明示同意后使用） | 去标识化的内容，不含个人敏感信息 | 特定高级功能 |

**境外数据传输说明**：如使用境外 LLM 服务，我们会在调用前弹窗提示并获取您的单次授权。境外传输严格遵守《数据出境安全评估办法》《标准合同办法》要求，且不传输身份证号、手机号等敏感个人信息。
| **TikHub** | 您提交的社媒 URL | 采集公开视频数据 |
| **支付服务商**（微信支付、支付宝） | 订单号、金额、您的支付标识 | 处理支付 |
| **短信服务商**（阿里云、腾讯云） | 您的手机号、验证码 | 发送验证码和通知 |
| **云服务商**（阿里云、腾讯云） | 加密后的业务数据 | 数据存储和计算 |

这些服务商均与我们签署了严格的数据保密协议，仅可按我们的指示处理数据。

#### 4.2.2 依法披露

在以下情形下，我们会根据法律要求披露您的信息：

- 响应司法机关、行政机关、监管机构的合法调查
- 为保护平台、其他用户、公众的合法权益
- 国家安全、公共安全、公共卫生、重大公共利益相关

#### 4.2.3 经您授权的共享

- 您通过"分享海报""契合度报告""作品授权"等功能主动分享的内容
- 您授权代理查看您在平台的业务数据（仅限您绑定代理时）

#### 4.2.4 业务变更

如果发生合并、收购、资产转让、破产清算等情况，您的信息可能作为业务资产转移至承接方。承接方需继续受本政策约束，如调整使用目的，会重新征得您的同意。

## 五、我们如何保护您的信息

### 5.1 技术措施

- **传输加密**：全站 HTTPS，敏感数据 TLS 1.3 加密传输
- **存储加密**：密码采用 bcrypt 单向加密，敏感信息（身份证、银行卡）AES-256 加密存储
- **访问控制**：内部人员分级权限，访问需二次认证和日志记录
- **网络安全**：WAF 防护、入侵检测、定期漏洞扫描

### 5.2 管理措施

- 数据安全专员岗位设立
- 全员隐私保护培训
- 定期数据安全审计
- 应急响应预案（发生数据泄漏事件时 72 小时内通知监管机构和受影响用户）

### 5.3 但请您知悉

- 互联网并非绝对安全的环境，我们会尽力保护但**不能保证绝对安全**
- 请您妥善保管账号密码，不要在公共设备保持登录
- 如发现账号异常，立即通知平台

### 5.4 数据跨境

**您的个人信息原则上存储在中华人民共和国境内**。如业务必需跨境传输（如使用境外 LLM 服务），会提前告知并征得您的明示同意，并采取符合法律要求的安全措施。

## 六、数据保留期限

| 数据类型 | 保留期 |
|---------|--------|
| 账号基础信息 | 账号存续期间 + 注销后 6 个月（法律要求） |
| 交易记录 | 自交易发生起 5 年（税务法律要求） |
| 日志信息 | 6 个月（安全审计要求） |
| 用户生成内容 | 账号存续期间（最长 3 年），注销后永久删除或匿名化 |
| 实名认证信息 | 账号存续期间 + 注销后 6 个月 |

**您申请注销账号后**：

- 个人身份信息在 6 个月后删除
- 业务数据立即删除或匿名化
- 仅法律要求必须保留的部分继续存档（如交易凭证）

## 七、您的权利

根据《个人信息保护法》，您对自己的个人信息享有以下权利：

### 7.1 知情权与决定权

- 您有权知道我们如何处理您的信息
- 您有权决定哪些信息可以被处理

### 7.2 查询权、复制权

- 随时在"账号设置"查看平台保存的您的信息
- 可申请导出您的完整数据副本（每 6 个月 1 次，如需更频繁可能收取成本费用）

### 7.3 更正权

- 发现信息不准确时，可自行修改或联系客服更正

### 7.4 删除权

在以下情形下您可要求删除信息：

- 我们超出约定用途处理您的信息
- 您注销账号
- 我们违反法律法规
- 其他法定情形

### 7.5 撤回授权

- 您可以随时撤回之前给予的任何授权（撤回后不影响之前已发生的处理）

### 7.6 账号注销

- 可通过"设置→账号注销"申请注销
- **30 天冷静期**：注销提交后 30 天内可登录取消注销，30 天后永久删除
- 注销前请结清佣金、消耗积分，**30 天冷静期过后积分和佣金全部失效**

### 7.7 投诉与响应

- 您对隐私保护有任何问题，可通过客服邮箱联系
- 我们承诺在 **15 个工作日**内响应您的请求
- 如对处理结果不满意，可向网信办、工信部等监管机构投诉

## 附录：常见问题 FAQ

**Q1: 我不想让 AI 学习我的使用数据，怎么办？**
A: 在"设置→隐私设置"关闭"允许使用数据改进模型"开关。关闭后不影响您正常使用服务，但个性化推荐可能减弱。

**Q2: 我的品牌信息会不会被别的用户看到？**
A: 不会。品牌信息严格隔离，仅您本人和您授权的代理可查看。

**Q3: 我上传的语料、视频会不会被平台公开使用？**
A: 不会。上传内容仅用于服务您本人（如训练您的 AI 画像），未经您明确同意不会公开或用于其他用途。

**Q4: 注销后我的数据真的会被删除吗？**
A: 是的。注销后 6 个月内删除身份信息，立即删除或匿名化业务数据。仅法律要求保留的交易凭证会继续存档，但与您的身份已解耦。

**Q5: AI 生成的内容属于谁？**
A: 在您完全遵守协议和付费的前提下，您拥有使用权。详见《用户服务协议》第 7 条。
